# 08 依赖清单

| 用途 | 坐标 | 说明 |
|---|---|---|
| 基础能力（Base58/Base32 等） | `io.gitee.visual0zz:flora-root` | 基础编解码沉淀于 flora-root.codec；flora-sanctum 复用，不自建 |
| 加密 | `org.bouncycastle:bcprov-jdk18on` | 可选 `bcpkix-jdk18on`（证书场景） |
| Git 同步 | 本地 git 命令（`ProcessBuilder` 调系统 `git`） | 同步是可选能力，目标机器需装 git |
| UI | 内置 `java.desktop`（Swing/AWT） | 纯 JDK 无额外依赖，jlink 可打包；外观用 `com.formdev:flatlaf`（现代扁平主题，light/dark/system） |
| SVG 图标 | `com.github.weisj:jsvg`（SVG Salamander） | 纯 Java 把 resources/icons 下矢量图标渲染为 Swing ImageIcon，用于文件夹/条目图标 |
| 外部密钥服务 HTTP | 内置 `com.sun.net.httpserver.HttpServer` | 无额外依赖（JDK 自带），本地 localhost + JSON，见 02 |
| 测试 | JUnit 5 | 遵循 test.cmd / test-slow.cmd 分工 |

## 版本策略

- 以当时最新稳定版为准；升级后在本文件更新，并同步检查 02 中的算法是否受影响。
- 所有依赖通过根 POM 的 dependencyManagement 统一管理。
