# 探索：自反函数 f(x,seed)=y 且 seed 反推困难

日期：2026-08-18
类型：算法/密码学探索笔记
状态：探索中（实验验证完成，构造 A 为当前推荐）

> 目标：构造 `f(x, seed) = y`，满足
> 1. **对合**：`f(f(x, seed), seed) = x`
> 2. **seed 反推困难**：已知大量 (x, y) 样本，从计算层面无法恢复 seed

这个设定（"公开对合 + 秘密参数 + 样本反推"）在文献中缺少系统性刻画，属于开放性区域。本文梳理数学结构、候选构造族、安全性论证，并用 `flora-playground` 实验验证。

## 1. 问题形式化

固定 seed 时，`f(·, seed)` 是定义域上的**对合**（involution）：`f∘f = id`。

**结构定理**：一个对合的轨道分解只含两类——
- **固定点**：`f(x) = x`
- **2-环**：`x ↔ y`，`f(x) = y, f(y) = x`

因此"seed 反推困难"意味着：**给出 2-环的若干条边 (x, y)，恢复决定配对规则的参数 seed 困难**。

## 2. 构造族与安全性分析

### 构造 A（推荐）：PRF 平移对合

```
输入 x = (L, R)，两半等长（如各 128 位）
f((L,R), seed) = (L ⊕ H(seed, R), R)     H = 截断 SHA-256 / HMAC
```

- **对合性**：`(L ⊕ H(R)) ⊕ H(R) = L`，R 不变。✓
- **seed 反推**：攻击者拿样本 `((L,R), (L⊕H(R), R))` 即得 `H(seed, R) = L ⊕ y_L`。选择 `x=(0,R)` 可对任意 R 拿到 H 的输出 → **对 H(seed, ·) 的完整输入输出 oracle**。恢复 seed = PRF 密钥恢复，需要 `2^{|seed|}` 次穷举。
- **安全性论证**：若 H 是 PRF（HMAC-SHA256 视为随机函数），任何多项式时间攻击者从 oracle 恢复密钥的概率可忽略。这是标准密码学假设，不是"数学上未解决"的部分。
- **结构弱点**：R 半恒等，函数"混合度"低。这是满足两条性质的最简形式，见开放问题 1。

### 构造 G（充分混合对合，推荐）：镜像 Feistel

```
输入 x = (L, R)，两半等长；轮函数 F_i(seed, ·) = 截断 SHA-256(seed ‖ ·)
轮序列取镜像对称（如 L,R,L 或 L,R,L,R,L），每个单轮是单侧 XOR：
    L ← L ⊕ F(seed, R)      （对合）
    R ← R ⊕ F(seed, L)      （对合）
```

- **对合性**：每个单轮自对合；对称轮序列 `E = a_n∘…∘a_1`（a_i = a_{n+1-i}）满足
  `E⁻¹ = a_1∘…∘a_n = E`，故整体对合。
- **充分混合**：两半都动，F 的雪崩 + 多轮传播。实验 3/5/7 轮雪崩平均变化率均 **0.500**（理想值）。
- **seed 反推**：seed 是 F 的密钥；恢复 seed = 对"镜像 Feistel 对合 PRP"的密钥恢复（穷举 2^{|seed|}）。
  无标志位、无需可逆（对比构造 B / 共轭构造）。

> 镜像 Feistel 的安全性对标 Luby-Rackoff 范式：在 F 为 PRF 的假设下，这类结构构成
> "对合伪随机置换（involution PRP）"。这是文献中"充分混合且可参数化的安全对合族"
> 的缺口所在，本构造给出了一个可实验验证的实例。

### 构造 B：标志位嵌入任意可逆函数

```
输入 x = (b, v)，b ∈ {0,1} 为标志位，h 为可逆函数
F(0, v) = (1, h(v));   F(1, w) = (0, h⁻¹(w))
```

- **对合性**：`F(F(0,v)) = F(1,h(v)) = (0, h⁻¹(h(v))) = (0,v)`；另一侧对称。✓
- **seed 反推**：若 `h` 是陷门可逆函数（如 RSA 加密），样本给出 `h` 的 oracle，求 `h⁻¹` 的秘密 = RSA 求逆（私钥恢复），困难。✓
- **缺点**：输入被占 1 位标志；h 必须是严格可逆（非多对一）。

### 构造 C（反例）：GF(2^k) 上逆元 + 平移

```
f(x) = (x ⊕ s)⁻¹ ⊕ s        （GF(2^k)，加法为 XOR）
```

- **对合性**：`( (x⊕s)⁻¹⊕s ⊕ s )⁻¹ ⊕ s = ( (x⊕s)⁻¹ )⁻¹ ⊕ s = x`。✓
- **攻破**：对每对样本 `(x⊕s)(y⊕s) = 1`（域乘）。展开 `xy ⊕ (x⊕y)s ⊕ s² = 1`，**两对样本相减消去 s²**，直接解出 `s`。实验两对样本恢复成功。
- **注意**：GF(p)（加法为 mod p 加法）上此式**不成立**（`(x+s)⁻¹+2s` 无法抵消），平移抵消依赖 XOR 的自反性——这是学习到的关键点。

### 构造 D（反例）：幂对合

```
f(x) = x^s mod p，要求 s² ≡ 1 (mod p-1)
```

- **对合性**：`x^{s²} ≡ x`。✓（实验 p=113 时 8 个候选 s 全部验证通过）
- **攻破**：`s² ≡ 1 mod (p-1)` 的解数是 `2^{ω(p-1)+1}`（ω 为不同素因子数），**候选空间极小可枚举**（p-1=112 时仅 8 个）。seed 无秘密空间，即便恢复形如 DLP 也无关紧要。

### 构造 E（反例）：仿射对合

```
f(x) = A·x ⊕ b，A² = I 且 A·b = b（GF(2) 上线性对合）
```

- **攻破**：`f(0) = b` 单样本泄露平移；对基向量 eᵢ，`f(eᵢ)⊕f(0) = A·eᵢ` 给出 A 的列。33 个样本线性代数恢复 A、b。✓

### 构造 F（反例）：Möbius 对合（PGL(2,p)）

```
f(x) = (ax+b)/(cx−a) mod p     （迹零矩阵 [[a,b],[c,−a]] 满足 M²=λI）
```

- **对合性**：PGL(2,p) 中迹零矩阵平方为标量 → 分式线性变换对合。✓
- **攻破**：`y = (ax+b)/(cx−a) ⟹ c·xy − a·(x+y) − b = 0`，关于 (c,a,b) 的**线性方程**。3 个样本构成齐次系统，rank 2（真实解存在），前两行**叉积**即 (c,a,b) 比例。实验 3 样本恢复成功。

## 3. 实验结果（flora-playground）

实验代码：`flora-playground/src/main/java/com/flora/playground/InvolutionExplore.java`
（运行：`java -p flora-playground/target/classes:flora-root/target/classes:<jsvg.jar> -m com.flora.playground/com.flora.playground.InvolutionExplore`）

| 构造 | 对合性验证 | 恢复 seed |
|---|---|---|
| A（PRF 平移） | 20000 组 0 失败 | 8 位 0ms → 16 位 7ms → 24 位 238ms（指数增长） |
| B（标志位嵌入） | 1000 组 0 失败 | 依赖陷门函数（概念验证） |
| C（域逆+平移） | 通过 | **2 对样本恢复** s |
| D（幂对合） | 8 个候选全部通过 | 候选空间仅 8 个 |
| E（仿射对合） | 通过 | 单样本泄露 b，33 样本恢复 A |
| F（Möbius 对合） | 通过 | **3 样本恢复** (a,b,c) 比例 |
| **G（镜像 Feistel）** | 3/5/7 轮各 5000 组 0 失败 | 8 位 0ms → 16 位 28ms（指数增长） |

雪崩测试（构造 G）：输入任意 1 位翻转，输出平均变化率 **0.500**（理想值）——两半均充分扩散。

### 可预测性（密钥恢复 vs 不可区分，两个层级）

**构造 A 可预测**：样本 `(L,R) → (L⊕H(seed,R), R)` 直接暴露 `H(seed,R)`。拿到同一 R 半的一个样本，即可预测该 R 下**所有**新 x 的结果（实验 100% 命中）。这是"混合度低"的直接后果。

**构造 G 不可预测**（挑战测试，5 轮、64 位半块、50 训练样本）：
- 随机挑战 x\*（排除落在训练集内的平凡对合情形），50% 给真实 y\*、50% 给随机 z；
- 攻击者无结构可利用，总正确率 **54.8%** ≈ 随机 50%（500 轮统计波动内）——训练集之外的新 x 无法预测，真实值与随机值不可区分。
- 唯一可"预测"的是对合平凡性质：已知 `(x,y)` 则 `f(y)=x`——等价于已知样本本身，不泄露新信息。

> 结论：**"恢复 seed 困难"（弱）与"不可预测 / 不可区分"（强）是两个层级**。构造 A 满足前者不满足后者；构造 G 两者都有希望成立（依赖镜像 Feistel 的对合 PRP 归约，见开放问题 1）。

## 4. 结论

- **构造 G（镜像 Feistel）同时满足全部三条**：充分混合（雪崩 0.500）+ 对合（对称轮序列）+ seed 反推困难（PRF 密钥恢复）。
- **构造 A**（PRF 平移）满足对合与 seed 反推困难，但混合度低（R 半恒等）。
- 域逆+平移（C）、幂对合（D）、仿射（E）、Möbius（F）均有代数结构使少量样本即可恢复参数，**不安全**。
- 构造 B 是理论可行的备选，但需要陷门可逆函数与标志位。

## 5. 开放问题

1. **镜像 Feistel 的安全性归约**：构造 G 是否构成标准意义下的"对合 PRP"（即与随机对合不可区分）？对称轮序列 `a_n∘…∘a_1` 的结构特殊（轮函数共用、镜像对称），Luby-Rackoff 的经典归约不直接适用，需要专门证明——这可能是文献缺口最核心的地方。
2. **轮数充分性**：实验显示 3 轮雪崩已达 0.500（扩散由 F 的雪崩主导）；但**不可区分性**可能需要更多轮。轮数与安全边界的定量关系待研究。
3. **对合单向性**：是否存在自然的"对合单向函数族"（involution OWF）？文献（如 RSA 签名、Rabin 签名）使用陷门对合，但"公开对合 + 样本反推参数"的困难性刻画很少。
4. **构造 A 的边界**：若 R 半空间小（如 32 位），H(seed,R) 样本会重复；R 半的熵需求是多少？
5. **语义**：对合是否必须"看起来随机"？用户需求的"seed 反推困难"是否需要**不可区分性**（样本不可与随机对合区分），还是仅**密钥恢复困难**？构造 A 满足后者不满足前者；构造 G 两条都有希望成立。
