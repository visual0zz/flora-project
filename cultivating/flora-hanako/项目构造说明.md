# Flora Hanako 工程构造说明

> 位置：`cultivating/flora-hanako`
> 定位：Java 版 openhanako 个人 AI 助理，采用 `addition/design/idea20260809-openhanako-java实现形态.md` 的**方案 B（轻量嵌入式 Web）**。

## 为什么是方案 B

依据设计文档第 3~5 节对比：方案 B 在「依赖少（4~6 个直接依赖）/ 做起来最简单（HTTP+WS+SSE 开箱即用）/ 好用（现代浏览器 UI）」三个维度同时占优。
选型结论：服务端用 Javalin（唯一主第三方依赖），业务逻辑全部落在 flora-root 基座能力上，前端用现代 Web 技术，跨平台体验统一。

## 技术决策

- **Javalin 6.3.0** 作为唯一主第三方依赖：内置 Jetty，一库提供 HTTP + WebSocket + 静态资源托管。
- **无 JPMS module-info**：Javalin 6 的 Jetty 传递依赖构成完整 JPMS 模块图，作为命名模块编译会触发大量自动模块名问题；本工程以**类路径应用**方式构建，规避该复杂度（符合方案 B「做起来最简单」）。
- **序列化复用 `com.flora.codec.json`**：`ctx.json()` 依赖 Jackson，故自定义 `json(ctx, obj)` 用 `JsonBuilder` 输出，避免引入 Jackson。
- **LLM 复用 `com.flora.ai.api.AiApi`**：提供商经 `AiApi.registerAll` 注册并展开能力端点，路由按模型角色（CHAT/UTILITY/HEAVY）选端点；对话用 `StreamingClient.stream` 流式推理。
- **前端零构建**：原生 HTML/CSS/JS 打包进 `src/main/resources/web`，由 Javalin 的 classpath 静态资源直接托管，浏览器即 UI。

## 目录结构

```
src/main/java/com/flora/hanako/
├── Main.java                 # 启动入口
├── core/
│   ├── HanakoEngine.java     # 引擎：Agent/Session/记忆/工具编排，驱动对话轮（含工具调用循环）
│   └── model/                # ChatMessage / Session / Agent / ProviderConfig / ModelConfig / MemoryFact / Jian
├── tools/                    # Tool 接口 + Read/Write/Terminal/WebFetch/Todo + ToolRegistry
├── storage/                  # JsonStores（原子写）+ TaggedFactStore（标签化事实存储）
└── server/                   # HanakoServer（Javalin 引导）+ ApiHandler（REST）+ ChatWebSocket（WS）
src/main/resources/web/       # 前端：index.html / app.js / styles.css（暖纸主题）
src/test/                     # 单元测试 + 服务冒烟测试
```

## 运行

```bash
# 共享 jar 先 install（首次）
./mvnw -pl flora-root -am install -DskipTests
# 运行（默认端口 4567）
./mvnw -pl cultivating/flora-hanako -am compile exec:java -Dexec.mainClass=com.flora.hanako.Main
# 或打包后运行
java -jar cultivating/flora-hanako/target/flora-hanako-0.1.jar
```

浏览器访问 `http://localhost:4567`，在设置中配置模型提供商（OpenAI 兼容协议）与三个模型后开始对话。

## 已实现功能（复刻 openhanako）

- 记忆：标签化事实存储，记忆检索注入 system prompt。
- 人格：Agent 独立 identity/ishiki 模板，可增删与编辑。
- 工具：文件读写、终端命令、网页抓取、记忆沉淀（/remember）。
- 书桌：笺（Jian）便签，Agent 主动读取并执行。
- 多会话：按 Agent 隔离的会话列表。
- UI：暖纸视觉、流式对话、思考块、工具块、斜杠命令。
