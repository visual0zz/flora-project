# 07 UI 设计

## 选型：Swing（纯 JDK）

- **Swing / AWT**（`java.desktop` 模块，JDK 自带），不引入 JavaFX。
- **理由**：JavaFX 打包分发困难（含平台原生库，jlink 不支持，见 addition/exploration/explore20260816-Java桌面打包与JavaFX困境全景剖析.md）。Swing 纯 JDK：
  - **jlink 可打包精简 JRE**（无原生库/无 classifier），免装 Java、一次打包。
  - 无 module-path/classifier 麻烦。
- 覆盖密码管理器所需桌面能力：
  - 系统托盘（AWT SystemTray）；
  - 剪贴板写入与定时清空（AWT Toolkit + Clipboard）；
  - 自动锁定定时器（java.util.Timer + 活动监听）；
  - TOTP 倒计时显示（java.util.Timer 轮询剩秒）。

## UI 与 core 的边界

- UI 只调用 core 公开 API：不解密、不直接读写密文、不碰 Git。
- 便于未来增加 CLI / Web 端复用 core。
- app 是唯一可执行入口：无参数启动 Swing GUI，有参数处理 CLI 命令（见 01）。

## 界面组成（已实现）

- 解锁屏：主密码输入 + 打开/新建仓库（目录选择）。
- 主界面：组树（JTree）+ 条目列表（JList）+ 编辑面板（字段/TOTP/复制）；同步按钮（完全托管时显示）、设置、锁定。
- 托盘菜单：锁定、复制密码、退出。
- 设置页：主题、自动锁定时长、剪贴板清空时长。

### 树形控件与列表（扁平化）

- **无"全部"根**：JTree 隐藏根，直接平铺"密码库 / 图标 / SSH 密钥 / 远程"四区段为顶层。
- 文件夹节点只显示**名字**（空白名兜底"未命名"），不显示 uuid；顶层文件夹挂在"密码库"区段下。
- 选中文件夹时右侧列表**混合展示内部子文件夹 + 条目**（文件夹图标 / 条目图标区分）；**单击子文件夹→右侧编辑面板编辑该文件夹，双击→进入该文件夹**（树联动选中）。

### 新建流程（不弹对话框）

- 新建条目：直接以空白名创建（含空密码字段），自动选中并在编辑面板打开，由用户改名/填密码后保存。
- 新建文件夹：直接以空白名创建，树选中并打开文件夹编辑表单改名。

### 编辑页面

- **条目编辑**：名称 + 各字段（值 + kind 下拉 + 删除）+ 保存/添加字段/复制密码/选择图标；TOTP 字段显示验证码。
- **文件夹编辑**：名称 + 保存（`renameGroup`）+ 删除文件夹（递归）。
- 图标 / SSH 密钥 / 远程区段各有对应详情面板。

### 自定义字段 kind（下拉选择）

- **`FieldKind` enum**（core）定义已知 kind 集合（text/password/totp/url/externalKey/remote），存储仍是字符串。
- 添加字段对话框与条目编辑面板的字段行均提供 **kind 下拉**；**库内未预定义的 kind 自动追加进下拉选项**（向后兼容：新版本引入的未知 kind 也能正常选择/展示，不丢失）。
- `null` 视为 `text`；`fieldName=="password"` 且 kind 为 text/null 时按密码字段处理（标红、必填、可复制）。

## 主题与外观

- **FlatLaf（已引入）**：`com.formdev:flatlaf`，纯 Java，不破坏 jlink 打包。明 `FlatLightLaf` / 暗 `FlatDarkLaf` / 跟随系统走系统 L&F。
- **主题模式**：明 / 暗 / 跟随系统（探测 OS 明暗偏好），存于用户配置。

## 用户配置目录（~/.flora-sanctum/）

- **全局配置目录**：`<用户主目录>/.flora-sanctum/`（用户级，跨所有仓库一份）。
- **存放内容**（全局信息，随用随加）：
  - `config.json`：外观偏好（主题 `light`/`dark`/`system`）、自动锁定时长、剪贴板清空时长、同步开关等用户级设置。
  - 未来其它全局信息（最近打开的仓库、窗口位置、非密码偏好）统一放此目录。
- **不存放**：任何密码学材料、密钥、密文块——那些在仓库内。本目录仅存用户级非敏感配置。
- **隐私边界**：目录名 `.flora-sanctum` 无密码含义；配置不落明文敏感数据。

## 打包与分发

- **开发/本地**：`java --module-path <app.jar>:<lib> -m com.flora.sanctum.app/com.flora.sanctum.app.Main`（并列多 jar）。
- **可分发包**：Swing 纯 JDK → **jlink 可打包精简 JRE**（免装 Java）；前提是模块图内无自动模块（第三方 jgit/bc/sshd 需转显式模块，见探索文档）。
- **现状**：第三方为自动模块，jlink 受限 → 当前用"并列多 jar + 启动脚本 + zip"（需预装 Java）。

## 备选方案

- JetBrains Compose Multiplatform Desktop：界面更现代、声明式；代价是引入 Kotlin 与新的构建配置。
- Java 后端 + 系统浏览器（Desktop.browse + 本地 HTTP）：jlink 可一次打包、免装 Java，但 UI 为网页体验（详见探索文档）。
