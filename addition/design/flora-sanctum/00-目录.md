# flora-sanctum 设计文档目录

## 项目一句话

flora-sanctum 是一个密码管理器：密码库是一个 Git 仓库，工作区中存放大量散碎的密文文件；加密用 Bouncy Castle，Git 操作用 JGit。核心性质是"明文的局部修改只引起密文的局部修改"，从而获得小粒度 diff、可合并的并发修改，以及"远端即备份"。

## 修改指引

每个文档只覆盖一个方面，架构审查与调整时：

- 改密码学方案（KDF/算法/文件格式）→ 只改 02
- 改仓库布局/粒度/条目模型 → 只改 03
- 改同步策略/远端协议 → 只改 04
- 改界面框架/交互 → 只改 05
- 改安全策略/威胁模型 → 只改 06
- 改依赖 → 只改 07
- 改计划/验收 → 只改 08

跨文档的联动修改（如换算法同时影响 02 与 07）需同时更新涉及文档，各文档头部"关联文档"用于提示此类联动。
