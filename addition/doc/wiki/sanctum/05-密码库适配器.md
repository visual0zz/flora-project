# 05 密码库适配器

密码管理 schema 是插在通用对象存储（04）之上的适配器，全部约定建立于 key + 对象。换成其他数据结构时只换适配器，底层不动。

## 数据结构树化（架构重构后）

`Sanctum = Vault(密钥状态) + LibraryConfig(配置数据) + List<DataTree>(数据树)`：

- **Vault**：解锁后的密钥状态——KEK、manifest（版本 / `crypto` 算法套件 / KDF 算法与参数 / salt / seed）、keyId 索引、仓库时间戳锚点，以及解锁时经 keyId 扫描命中 `type==root` 定位并登记的根对象 uuid（见 02）。
- **LibraryConfig**：配置数据——远端配置只读视图 + 仓库级设置（type=config 节点，加密存储于 config category 下：主题/自动锁定时长/剪贴板清空时长，见下）。
- **List<DataTree>（四棵）**：按**节点类型**分类——`ObjectTree`（GROUP/ENTRY/FIELD/CUSTOM_FIELD：组/条目/字段）、`IconTree`（ICON）、`SshKeyTree`（SSH_KEY）、`RemoteTree`（REMOTE）。四棵树共享同一棵 DEK 树：root 隐含组持 rootDek，普通 group 持 dek1/dek2 双 DEK（见下），仅按类型分树。
- **节点负责操作**：新建/编辑/删除等由树节点承担——`GroupNode.createEntry/createChildGroup`、`EntryNode.updateBuiltins/createField`、`FieldNode.updateValue/updateKind`、`RemoteNode.update` 等；`Sanctum` 只做门面（打开/解锁/关闭 + 树列表 + 跨树查找 + 委托换主密码/GC/导出）。
- **接口类型化**：节点方法返回/接收类型化值（`EntryNode.password()`、`FieldNode.kind()`），不向 app 泄漏 flora-root `JsonObject`。
- **GC / 换主密码 / 导出** 拆为独立组件（`GarbageCollector`/`MasterKeyRotator`/`ArchiveExporter`），manifest 读写收敛为 `ManifestStore`。
- **sync/server 归属 app**：git/ssh 同步（`app.sync.SyncService`）与 HTTP 外部密钥服务（`app.server.SanctumHttpServer`）位于 app，core 专注数据读写。

## 隐私目标

外部（无主密码）拿到仓库，最多只能看到一堆随机命名的密文文件；**看不到**组名、条目名、字段名、字段数量、字段值，连组的数量与嵌套形状也不可见，字段对象的大小也无法关联到具体条目。

## 逻辑模型

- 文件夹（组）：树形，节点 = 组记录（SECRET 对象，含父组引用与文件夹 DEK）。
- 条目 = **条目记录 + 预设字段块 + 自定义字段块**：
  - 条目记录（SECRET 对象）：结构信息（name/parent/icon），**不含字段值**；
  - **预设字段**（password/url/username/labels/notes）：各自一个 SECRET 块（type=field，name 固定为预设名），**随机 uuid、自述 parent 指向条目**，与自定义字段结构一致，GUI 固定显示、不可删除；
  - **自定义字段**：各自一个 SECRET 块（type=field，name 任意，kind 可选），自述 `parent`（所属条目）+ `name`。
- 目录：**非持久对象**——解锁时扫描全部对象、解密并按内容类型分类，在内存中构建；锁定即丢弃。
- **无锚点、无保留名**：所有对象都是随机 UUID 文件，靠内容自描述定位（预设字段经 `parent`+`name` 定位，而非确定性 uuid）。

## 映射：逻辑概念 → key 与对象

| 逻辑概念 | 底层表示 |
|---|---|
| 根对象（type=root，持 rootDek 对，块以 KEK 加解密） | SECRET 对象；uuid 随机生成、不可定位（不记入 manifest、不由 KEK 推导），解锁时扫描全部块经 keyId 命中 `type==root` 定位（见 04） |
| 分隔层节点（type=category，共 5 个：password/icon/sshKey/remote/config；各持独立 DEK 对，parent=根对象） | SECRET 对象；uuid 随机生成、不可定位，解锁时扫描经 keyId 命中 `type==category` 并按 `category` 字段登记（见 04） |
| 组记录（type/name/parent/dek1/dek2） | SECRET 对象；key = `<组UUID>` |
| 条目记录（type/name/parent/icon） | SECRET 对象；key = `<条目UUID>` |
| 预设字段（type=field，name 固定预设名，parent 指向条目） | SECRET 对象；key = `<随机UUID>` |
| 自定义字段（type=field；自述 parent + name + kind） | SECRET 对象；key = `<随机UUID>` |
| SSH 私钥（type=sshKey） | SECRET 对象；key = `<随机UUID>` |
| 远端配置（type=remote，独立类型） | SECRET 对象；key = `<随机UUID>` |
| 自定义图标（type=icon，parent 指向 icon category 节点） | SECRET 对象；key = `<随机UUID>` |

- **统一按 uuid 分片到两层目录**：对象文件 = `{uuid第1字符}/{第2字符}/{后30字符}.md`（见 04），**无更深层嵌套、无保留名、无明文/密文前缀**；文件外观完全一致，外部无法区分明文与密文。对象 uuid 即由该路径反推，不在块内冗余存储。
- **内容自描述**：解密负载带 `type` 字段（root/group/entry/field/sshKey/icon/remote，均为 SECRET 对象；manifest 为明文引导块，见 04），解锁扫描按 type 分类定位。各类型节点共享同一棵 **DEK 树**（见下）：root 隐含为"组"持 rootDek 对，普通 group 持 `dek1`/`dek2` 双 DEK；外部密钥是 field 的 `kind="externalKey"`（远端配置已独立为 type=remote，见下）。
- 全部走 `put(uuid, data, codec, timestamp)`（当前适配器全密文）。
- 条目/组 id 在创建时用混合熵源（见 02"熵混合"）生成 UUID v4，**终身不变、与内容无关**；预设字段与自定义字段均为随机 uuid（预设字段靠 `parent`+`name` 定位，结构一致）。
- **仓库无用户内容明文对象**：当前适配器除 manifest 明文引导块（见 04）外全密文。

## 条目记录内容（加密 JSON）

```json
{
  "type": "entry",
  "name": "微博",
  "parent": "<组UUID>",
  "iconRef": { "type": "node:icon", "id": "<icon对象UUID>" }
}
```

- `parent` = password category 节点 uuid（顶层条目无所属组时）；`iconRef` 为自定义图标引用（见「统一引用结构 Ref」），非归属，`null` 表示无图标。
- **字段值不存于条目记录**：预设字段与自定义字段各自是独立块，自述归属（`parent`），目录扫描时按 `parent` 聚合出条目内容。
- **引用 vs 归属（彻底分离）**：`parent` 是层级归属（决定挂在树的哪、用哪个 DEK 加密）；**引用是另一回事，不算 parent**——group/entry 用 `iconRef` 字段（Ref）引用 icon 对象、remote 用 `keyRef`（Ref）引用 sshKey。

### 统一引用结构 Ref

`icon` / `keyRef` 等"指向另一个数据节点或内置资源"的引用统一收口为 `Ref` 结构（core 的 `com.flora.sanctum.core.model.Ref`），避免散落的字符串/uuid 写法：

- `type` 为 `"<scheme>:<kind>"` 复合串；`id` 为标识。
- **`node` 方案**：引用仓库内一个数据节点，`kind` **等于被引用节点的 `type` 标签**（`StoredNodeType`），`id` 为该节点 uuid——
  `node:icon`（→ ICON 节点）、`node:sshKey`（→ SSH_KEY 节点；引用的 `kind` 等于被引用节点的 `type` 标签 `sshKey`，即 `StoredNodeType.SSH_KEY.tag()`）。
- **`builtin` 方案**：引用应用内置资源（不进对象库），`kind` 为资源类别（目前仅 `icon`），`id` 为资源名（如 `folder`）——
  `builtin:icon`。
- 解析器按 `scheme` 前缀注册（`NodeRefResolver` / `BuiltinRefResolver`），`RefScan` 声明"节点类型 → 其引用字段名"的表，
  GC / 垃圾桶分类复用该表求可达块，取代此前的 `icon`/`keyRef` 字符串读取。遗留字符串（`builtin:name` 或裸 uuid）在读取时由 `Ref.parse` 自动桥接。

预设字段块（加密 JSON，随机 uuid，自述 parent，GUI 固定显示不可删除）：

```json
{ "type": "field", "parent": "<条目UUID>", "name": "password", "value": "..." }
```

- 预设字段名集合（`EntryFields.PRESET_NAMES`）：`password` / `url` / `username` / `labels` / `notes`。
- 预设字段与自定义字段结构一致：统一块 `type=field`，随机 uuid、`parent` 指向条目、按 `name` 定位（经 `childrenOf` 遍历匹配），不依赖确定性 uuid；value 为空则块不落盘（读取时回退读 entry 旧字段以兼容迁移）。预设/自定义的语义**完全由 `name` 是否在 `PRESET_NAMES` 区分**，与块 `type` 无关。
- **`createTime` / `updateTime` 不是字段块**：二者内联在**条目 JSON** 内（`createTime` 创建时写入、`updateTime` 任意对象块重写时刷新），只读。`EntryNode.updateTime()` 取条目自身与全部字段块 `updateTime` 的最大值，反映"条目任一部分最后被改"。

自定义字段块（加密 JSON，type=field）：

```json
{ "type": "field", "parent": "<条目UUID>", "name": "note", "value": "...", "kind": "text" }
```

**自定义字段统一格式**：`{ type:"field", parent, name, value, kind? }`。
- `parent`：所属条目 UUID（自下往上，字段自述归属）。
- `name`：字段名（自述，替代 entry 的 fields 字典键）；**预设字段名不可用于自定义字段**（创建时拒绝）。
- `value`：字段值（统一字符串）。
- `kind`（可选，**存在字段块内**，自描述呈现提示）：`text`（默认）/ `password` / `totp` / `url` / `externalKey` 等，仅作呈现/语义提示，非强类型。TOTP = `kind:"totp"`（种子在 value，用 JDK HmacSHA1 生成验证码，见 02）；外部密钥 = `kind:"externalKey"`（value 即密钥材料，供外部加解密服务，见 02）。
- **类型统一与兼容读取**：所有字段块（预设与自定义）落盘 `type` 一律为 `field`；旧库曾用 `predefField` / `customField` 两种 type 标签，`StoredNodeType.fromTag` 在读端将其统一映射为 `FIELD`，故读取不依赖历史 type 字符串。预设/自定义语义完全由 `name` 是否在 `PRESET_NAMES` 决定。
- **不新增字段对象类型**：TOTP、外部密钥都仍是 field 对象（type=field），只是 `kind` 不同；kind 随对象存储。

图标对象（`type:"icon"`）**层级归属**：`parent` 指向 **icon category 节点**（用该 category 的活跃 DEK 加密）；同时可被 group/entry 的 `iconRef` 字段**引用**（引用 ≠ 层级）。

## DEK 树（组密钥对）

**单一 data 根对象**（`type=root`，uuid **随机生成、不可定位**、不记入 manifest）块本身以 **KEK** 加解密，负载仅持 **rootDek 对（dek1/dek2，明文 base64）**（仓库级 keyId 种子已移至 manifest 的 `seed` 字段；见 02"根对象与 manifest 内容"）。此外存在 **5 个 category 分隔层节点**（`type=category`，`category` 字段为 password/icon/sshKey/remote/config 之一、`parent=根对象`、各持独立 DEK 对），是各类数据的顶层父与加密归属组；根对象与 category 均为"结构根"，不暴露为普通树节点（见下）：

- root 隐含为一个"组"（键 = rootObjectUuid）：其活跃 `dek2` 即 **rootDek**，**仅用于加密 category 分隔层节点**（category 块外层以 rootDek 加密，parent=根对象）。
- 每个 group 负载持 **dek1/dek2 双 DEK**（明文 base64；组块整体由**父组 DEK** 加密，链式）。新/改子节点一律用所在组的活跃 **dek2**；当某组不再有子节点引用退役中的 dek1 时触发惰性轮换（dek2 提升为 dek1 并新建 dek2，见 04）。
- **加密归属**：对象以其 `parent` 对应的 DEK 加密——组/条目用父组或所属 category 的活跃 DEK（顶层组/条目用 password category DEK），字段用所属条目的 DEK，图标/SSH 密钥/远端/设置分别用各自 category 的 DEK（均经 HKDF 派生 encKey）。块的 keyId 指向该 DEK。
- **一对多 / 一对一**：同一组内条目共享其 DEK（一对多）；不同组各自独立（反聚类到组粒度）。
- 普通块**不新增 keyRef 字段**——与哪把 DEK 配对完全由头部 `keyId` 决定。
- 解锁流程（惰性增量）：扫描块 → 找 manifest（明文块，type=manifest）→ 验证 MAC → Argon2id 派生 KEK → 取 manifest.seed（KEK 解密）得 repoKeyIdSeed → 扫描全部 cipher 块经 keyId 命中 `type==root` 定位根对象、KEK 解出 rootDek 对 → 再扫描经 keyId 命中 `type==category` 的 5 个分隔层节点并登记各 `category`→uuid 映射 → 沿组/条目链逐层解出各子组的 dek1/dek2（组块由父组/类别 DEK 加密）→ 每得 DEK 即时建 keyId 索引条目 → 普通块按 (nonce, keyId) 找 DEK 试解（见 02）。（任一数据类未发现对应 category 节点 → 旧格式被拒，见 03。）
- **新对象归属分隔层**：各类数据的顶层 `parent` 指向其对应的 **category 节点 uuid**（由 `Vault.categoryUuid(判别符)` 路由）：组/条目的顶层 parent = password category；图标 = icon category；SSH 密钥 = sshKey category；远端配置 = remote category；仓库设置 = config category。category 节点自身 parent = 根对象 uuid、以 rootDek 加密（见 04）。

- 字段名、字段数量、归属关系全部在加密的字段块/条目记录内：外部不可见。
- 字段对象大小可见，但因按 uuid 分片、无法与条目关联；明文/密文亦不可区分（见"映射"）。
- 组记录：`type`、`name`、`parent`、`dek1`、`dek2`。
- **写入时间戳不存于负载**：每块写入时间戳（毫秒，见 02"仓库时间戳"）存于**落盘前缀**（`timestamp:base64`），用于同步冲突仲裁（大者 wins）；负载 JSON 不携带时间戳字段。

## 局部性

- 改任一字段值 → 只重写该字段块（一个文件）；条目记录与其他对象不动，git 只见一个文件变化。
- 改名 / 移动条目（改 parent）→ 只重写条目记录。
- 改字段 kind（`updateKind`）→ 只重写该自定义字段块。
- 改名文件夹（`rename`）→ 只重写该 group 记录（加密归属沿用创建时的 DEK 路由）。
- 增删自定义字段 → 新建/删除 field 块（改字段自身，不动条目）。
- 换图标 → 新建/删除 icon 对象，更新引用方的 `iconRef` 字段（引用，非归属）。
- 换主密码 → **仅根对象块以新 KEK 重加密**（root uuid 随机生成、不变，rootDek 值亦不变，无需重新包裹任何子 DEK），category 节点与全部数据块**不受影响**；manifest 的 `seed`（KEK 加密）与 MAC 随验证密钥（KEK 派生）变化而重算重写（见 02）。

## 合并行为

- **字段值冲突 = 文件级**：两端改不同字段 → 不同字段块 → git 自动合并；两端改同一字段块 → 文件级冲突，按块前缀时间戳大者 wins（见 06 自动冲突策略），无需应用层三方合并。
- **条目记录冲突（低频）**：仅当两端同时改元数据或归属（如改名/改 parent）时发生 → 按时间戳大者 wins（见 06）。字段增删不冲突（各字段独立块，自述归属）。

## 一致性规则

- **无权威锚点**：事实来源 = 全部对象自身；解锁扫描 + 内容自描述构建内存目录，任何对象损坏/缺失只影响自身，目录可随时重建。
- 锁定期无目录（UI 显示锁定态）；解锁后目录构建于内存，锁定即丢弃。
- 条目归属：条目记录内 `parent` 为准；删组后其成员条目在扫描重建时发现组不存在，惰性归入普通对象树顶层（parent 指向所属 category 节点，无需立即改写文件）。
- 孤儿对象（条目删除后遗留的字段块等）无害（git 历史兜底），可提供显式 GC 命令。

## 负载类型字段定义

**结构根与分隔层**：仓库有两类"结构根"——① 唯一根对象（`type=root`，uuid **随机生成、不可定位**，不记入 manifest、不由 KEK 推导）；② **5 个 category 分隔层节点**（`type=category`，uuid 随机、不可定位），其 `category` 字段为 password/icon/sshKey/remote/config 之一、`parent=根对象`、各持独立 DEK 对。各类数据的顶层 `parent` 指向其 category 节点（组/条目→password，图标→icon，SSH 密钥→sshKey，远端→remote，设置→config），category 节点本身以 rootDek 加密。root 与 category 均为基础设施，**不暴露为普通树节点**（`ObjectTree.find` 对 `type==root`/`type==category` 返回 null）。（代码中无 RootTag/RootUuid 类；判别符集中在 `CategoryDisc` 枚举。）

所有对象负载统一 JSON，以 `type` 标识类型；密文块解密后按 `type` 分类；manifest 为明文引导块（见 02/04），是唯一带 `version` 的负载。**写入时间戳存于落盘前缀**（`timestamp:base64`，见 02"仓库时间戳"），不占负载字段。

### manifest（明文块）

| 字段 | 类型 | 说明 |
|---|---|---|
| version | int | JSON 结构版本 |
| type | string | 固定 `manifest` |
| crypto | string | 算法套件版本（值 `gcm-siv-1`，见 02） |
| kdf | string | 固定 `argon2id` |
| salt | string(base64) | Argon2id 盐，创建时生成、终身不变 |
| params | object | `{memoryKiB, iterations, parallelism}`：KDF 参数 |
| seed | string(base64) | 经 KEK 加密的 repoKeyIdSeed（仓库级 keyId 派生种子，32B），解锁时由 KEK 解密 |

> manifest **不记录根对象 uuid**：根对象 uuid 随机生成、不可定位，解锁时扫描全部块经 keyId 命中 `type==root` 定位（见 02）。manifest 的 `seed` 字段携带经 KEK 加密的 repoKeyIdSeed（仓库级 keyId 派生种子），解锁时由 KEK 解密。
> MAC **不在 JSON 内**，尾附于块末（`HMAC-SHA256(macKey, uuid‖时间戳‖信封头‖负载)`，见 02）。无 `warehouseTime` 字段：仓库时间锚点由 `WarehouseClock` 在解锁时扫描计算（会话基座），不持久化（见 02"仓库时间戳"）。

### root（根对象）

仓库唯一根对象（`type=root`），uuid **随机生成、不可定位**（不记入 manifest、不由 KEK 推导）；整块以 **KEK** 加解密，负载**仅持 rootDek 对（dek1/dek2）**，用于加密 5 个 category 分隔层节点（见 02"根对象与 manifest 内容"）。仓库级 keyId 种子已移至 manifest 的 `seed` 字段，根对象不再承载它。不暴露为普通树节点（`ObjectTree.find` 对 type=root 返回 null）。

| 字段 | 类型 | 说明 |
|---|---|---|
| type | string | 固定 `root` |
| dek1 | string(base64) | rootDek 退役键（惰性轮换用，明文存于 KEK 加密的根块内） |
| dek2 | string(base64) | rootDek 活跃键（加密 category 分隔层节点用） |

### category（分隔层节点）

仓库有 **5 个** category 分隔层节点（`type=category`），uuid 随机生成、不可定位；是各类数据的顶层父与加密归属组。每个节点 `category` 字段标识数据类（password/icon/sshKey/remote/config），`parent` 指向根对象 uuid，块整体以 **rootDek** 加密，负载持该类的独立 DEK 对。解锁时扫描经 keyId 命中 `type==category` 并按 `category` 字段登记 `判别符→uuid` 映射（`Vault.categoryUuid`）。不暴露为普通树节点（`ObjectTree.find` 对 type=category 返回 null）。任一判别符缺失即视为旧格式、解锁被拒。

| 字段 | 类型 | 说明 |
|---|---|---|
| type | string | 固定 `category` |
| category | string | 数据类判别符：`password`/`icon`/`sshKey`/`remote`/`config`（`CategoryDisc`，持久化不可改） |
| parent | string(uuid) | 根对象 uuid（结构根，层级顶端） |
| dek1 | string(base64) | 该类数据 DEK 退役键（明文存于 rootDek 加密的块内） |
| dek2 | string(base64) | 该类数据 DEK 活跃键（其下数据对象加密用） |

### group（组/文件夹，含文件夹 DEK）

每个 group 绑定 **dek1/dek2 双 DEK**（见 02/04），明文 base64 存于组块；组块整体由**父组 DEK**（顶层由 rootDek）加密。新/改子节点用活跃 `dek2`。

| 字段 | 类型 | 说明 |
|---|---|---|
| type | string | 固定 `group` |
| name | string | 组名 |
| parent | string | 父对象 UUID（32-hex）；顶层为 password category 节点 uuid |
| dek1 | string(base64) | 本组 DEK 退役键（仍可能被旧子节点引用） |
| dek2 | string(base64) | 本组 DEK 活跃键（新/改子节点加密用） |
| iconRef | Ref(object) \| null | 自定义图标引用（node:icon=icon 对象 UUID / builtin:icon=内置图标名；非归属） |
| order | number | 同级排序小数索引（appendOrder 生成，用于树形展示顺序） |

### entry（口令条目记录）

| 字段 | 类型 | 说明 |
|---|---|---|
| type | string | 固定 `entry` |
| name | string | 条目名 |
| parent | string(uuid) | 所属组/类别 UUID；顶层条目为 password category 节点 uuid |
| dek1 | string(base64) | 条目自身 DEK 退役键（条目持有的双 DEK 之一，明文存于父类别 DEK 加密的块内） |
| dek2 | string(base64) | 条目自身 DEK 活跃键（其字段块经此加密） |
| iconRef | Ref(object) \| null | 自定义图标引用（node:icon=icon 对象 UUID / builtin:icon=内置图标名；非归属） |
| createTime | number | 创建时间戳（毫秒，内联于条目 JSON，只读） |
| updateTime | number | 最后修改时间戳（毫秒，任意块重写时刷新，只读） |
| order | number | 同级排序小数索引 |

> 条目**不记录字段值**：预设字段与自定义字段各自为独立块，自述 `parent`；条目自身持有 DEK 对（其字段块经条目 DEK 加密），自定义图标由 `iconRef` 字段**引用**（非归属）。

### field（预设字段块）

| 字段 | 类型 | 说明 |
|---|---|---|
| type | string | 固定 `field` |
| parent | string(uuid) | 所属条目 UUID（自下往上，自述归属） |
| name | string | 预设字段名：`password`/`url`/`username`/`labels`/`notes` |
| value | string | 字段值（字符串形式；labels 为逗号分隔串） |

- 块 uuid 为随机 uuid，`parent`+`name` 定位/更新（与自定义字段块结构一致）；value 为空则块不落盘（读取缺失时回退读 entry 旧字段以兼容迁移）。
- GUI 固定显示全部预设字段行（无数据也显示空），**不可删除**。

### customField（自定义字段块，落盘 type=field）

| 字段 | 类型 | 说明 |
|---|---|---|
| type | string | 一律 `field`（与预设字段块一致；旧库 `customField` 标签读端映射为 `field`） |
| parent | string(uuid) | 所属条目 UUID（自下往上，自述归属） |
| name | string | 字段名（**不可用预设字段名**，创建时拒绝） |
| value | string | 字段值（字符串形式） |
| kind | string \| null | 呈现提示（存于块内，见上）。**已知集合 = `FieldKind` enum**（`text`/`password`/`totp`/`url`/`externalKey`）；**未知 kind 原样保留**（向后兼容：GUI 下拉会把库内未知 kind 追加进选项）。`null` 视为 `text`。kind 可修改（`updateKind`） |

### sshKey（SSH 私钥）

| 字段 | 类型 | 说明 |
|---|---|---|
| type | string | 固定 `sshKey` |
| parent | string(uuid) | sshKey category 节点 uuid（层级归属，用该 category 的活跃 DEK 加密） |
| name | string | 密钥名（可选） |
| value | string | PEM 私钥内容（与字段块 `value` 命名统一；用 sshKey category DEK 加密） |
| publicKey | string \| null | 公钥文本（形如 `ssh-rsa AAAA...` 的一行，可选） |

### remote（远端配置，独立类型）

远端配置是**独立类型** `type=remote`（`StoredNodeType.REMOTE`，`RemoteTree` 承载），扁平存 `name`/`url`/`keyRef`，顶层 parent 为 **remote category 节点 uuid**、用该 category 的活跃 DEK 加密：

| 字段 | 类型 | 说明 |
|---|---|---|
| type | string | 固定 `remote` |
| parent | string(uuid) | remote category 节点 uuid（层级归属） |
| name | string | 远端名（如 `github`） |
| url | string | 远端 URL（暴露托管商，故加密存储） |
| keyRef | Ref(object) \| null | 使用的密钥引用（node:sshKey=SSH 密钥对象 UUID；**引用，非归属**，见 sshKey） |

示例：`{ "type":"remote", "parent":"<remote category uuid>", "name":"github", "url":"...", "keyRef":{"type":"node:sshKey","id":"<sshKeyUUID>"} }`

### icon（自定义图标）

**层级归属**：icon 的 `parent` 指向 **icon category 节点**（层级归属，用该 category 的活跃 DEK 加密）——**与"被谁引用"完全分离**（层级 vs 引用彻底分离，见 02）。

| 字段 | 类型 | 说明 |
|---|---|---|
| type | string | 固定 `icon` |
| parent | string(uuid) | icon category 节点 uuid（层级归属） |
| name | string \| null | 图标名（导入文件名，可选） |
| data | string(base64) | 图标二进制数据（用 icon category DEK 加密） |
| format | string | 图标格式（如 `png`） |
