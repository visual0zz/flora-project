# 07 UI 设计

## 选型：JavaFX

- 与项目纯 Java + JPMS 技术栈一致，module-path 运行成熟。
- 不引入额外语言（Compose Multiplatform 会引入 Kotlin）。
- 覆盖密码管理器所需桌面能力：
  - 系统托盘（AWT SystemTray）；
  - 剪贴板写入与定时清空（Toolkit）；
  - 自动锁定定时器；
  - TOTP 倒计时显示。

## UI 与 core 的边界

- UI 只调用 core 公开 API：不解密、不直接读写密文、不碰 Git。
- 便于未来增加 CLI / Web 端复用 core。

## 界面组成（草稿）

- 解锁屏：主密码输入 + 打开/新建仓库。
- 主界面：解锁后显示左侧文件夹树（KeePass 式）+ 右侧条目列表 + 条目编辑页（字段读写），支持拖拽移动条目/文件夹；锁定状态无列表，只显示解锁屏。
- 托盘菜单：锁定、复制密码、显示 TOTP。
- 设置页：同步开关、自动锁定时长、剪贴板清空时长、外观（主题/强调色，见下）。

## 主题与外观（Material，自写 CSS）

- **风格**：Material 风格，**自写 JavaFX CSS**（零第三方 UI 依赖，符合纯 Java + JPMS），覆盖圆角、阴影、层次、间距、强调色。
- **主题模式**：**明 / 暗** 两种，可**固定配置**或**跟随系统**（探测 OS 的明暗偏好，随其切换）。
- **强调色**：可配置主题强调色，明暗主题共用一套变量驱动。
- **实现方式**：CSS 用**变量/查找表**（`-fx-*` 自定义属性）定义色板、圆角、阴影；明暗主题切换 = 切换根节点的 CSS 类/样式表，全局刷新。
- 界面元素（组树、条目卡片、按钮、输入框、解锁屏、托盘）均按此风格统一。

## 用户配置目录（~/.flora-sanctum/）

- **全局配置目录**：`<用户主目录>/.flora-sanctum/`（用户级，跨所有仓库一份）。
- **存放内容**（全局信息，随用随加）：
  - `config.json`（或 `settings.json`）：外观偏好（主题模式 `light`/`dark`/`system`、强调色、字号缩放等）、自动锁定时长、剪贴板清空时长、同步开关等用户级设置。
  - 未来其它全局信息（如最近打开的仓库列表、窗口位置、非密码类的用户偏好）统一放此目录。
- **不存放**：任何密码学材料、密钥、密文块——那些在仓库内（vaultKey/manifest/对象）。本目录仅存用户级偏好/非敏感配置。
- **隐私边界**：目录名 `.flora-sanctum` 无密码含义；配置不落明文敏感数据。可被忽略跟踪（若仓库系统可见）。

## 备选方案

- JetBrains Compose Multiplatform Desktop：界面更现代、声明式；代价是引入 Kotlin 与新的构建配置。
