# 07 UI 设计

## 选型：JavaFX

- 与项目纯 Java + JPMS 技术栈一致，module-path 运行成熟。
- 不引入额外语言（Compose Multiplatform 会引入 Kotlin）。
- 覆盖密码管理器所需桌面能力：
  - 系统托盘（AWT SystemTray）；
  - 剪贴板写入与定时清空（Toolkit）；
  - 自动锁定定时器；
  - TOTP 倒计时显示；
  - 全局快捷键（可选，jnativehook）。

## UI 与 core 的边界

- UI 只调用 core 公开 API：不解密、不直接读写密文、不碰 Git。
- 便于未来增加 CLI / Web 端复用 core。

## 界面组成（草稿）

- 解锁屏：主密码输入 + 打开/新建仓库。
- 主界面：解锁后显示左侧文件夹树（KeePass 式）+ 右侧条目列表 + 条目编辑页（字段读写），支持拖拽移动条目/文件夹；锁定状态无列表，只显示解锁屏。
- 托盘菜单：锁定、复制密码、显示 TOTP。
- 设置页：同步开关、自动锁定时长、剪贴板清空时长。

## 备选方案

- JetBrains Compose Multiplatform Desktop：界面更现代、声明式；代价是引入 Kotlin 与新的构建配置。
