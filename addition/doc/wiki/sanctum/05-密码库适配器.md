# 05 密码库适配器

密码管理 schema 是插在通用对象存储（04）之上的适配器，全部约定建立于 key + 对象。换成其他数据结构时只换适配器，底层不动。

## 数据结构树化（架构重构后）

`Sanctum = Vault(密钥状态) + LibraryConfig(配置数据) + List<DataTree>(数据树)`：

- **Vault**：解锁后的密钥状态——KEK、manifest（版本 / cryptoVersion / KDF 算法与参数 / salt / rootObjectUuid）、keyId 索引、仓库时间戳锚点（见 02）。
- **LibraryConfig**：配置数据——远端配置只读视图 + 仓库级设置（type=config 节点，加密存储于根对象下：主题/自动锁定时长/剪贴板清空时长，见下）。
- **List<DataTree>（四棵）**：按**节点类型**分类——`ObjectTree`（GROUP/ENTRY/FIELD/CUSTOM_FIELD：组/条目/字段）、`IconTree`（ICON）、`SshKeyTree`（SSH_KEY）、`RemoteTree`（REMOTE）。四棵树加密归属统一走 data 根 DEK，仅按类型分树。
- **节点负责操作**：新建/编辑/删除等由树节点承担——`GroupNode.createEntry/createChildGroup`、`EntryNode.updateBuiltins/createField`、`FieldNode.updateValue/updateKind`、`RemoteNode.update` 等；`Sanctum` 只做门面（打开/解锁/关闭 + 树列表 + 跨树查找 + 委托换主密码/GC/导出）。
- **接口类型化**：节点方法返回/接收类型化值（`EntryNode.password()`、`FieldNode.kind()`），不向 app 泄漏 flora-root `JsonObject`。
- **GC / 换主密码 / 导出** 拆为独立组件（`GarbageCollector`/`MasterKeyRotator`/`ArchiveExporter`），manifest 读写收敛为 `ManifestStore`。
- **sync/server 归属 app**：git/ssh 同步（`app.sync.SyncService`）与 HTTP 外部密钥服务（`app.server.SanctumHttpServer`）位于 app，core 专注数据读写。

## 隐私目标

外部（无主密码）拿到仓库，最多只能看到一堆随机命名的密文文件；**看不到**组名、条目名、字段名、字段数量、字段值，连组的数量与嵌套形状也不可见，字段对象的大小也无法关联到具体条目。

## 逻辑模型

- 文件夹（组）：树形，节点 = 组记录（SECRET 对象，含父组引用与文件夹 DEK）。
- 条目 = **条目记录 + 预设字段块 + 自定义字段块**：
  - 条目记录（SECRET 对象）：结构信息（name/parent/icon），**不含字段值**；
  - **预设字段**（password/url/username/labels/createTime/updateTime）：各自一个 SECRET 块（type=field，name 固定为预设名），**确定性 uuid** `nameUUIDFromBytes(entryUuid + "/" + name)`，GUI 固定显示、不可删除；
  - **自定义字段**：各自一个 SECRET 块（type=customField，name 任意，kind 可选），自述 `parent`（所属条目）+ `name`。
- 目录：**非持久对象**——解锁时扫描全部对象、解密并按内容类型分类，在内存中构建；锁定即丢弃。
- **无锚点、无保留名**：所有对象都是随机 UUID 文件（预设字段为确定性 uuid），靠内容自描述定位。

## 映射：逻辑概念 → key 与对象

| 逻辑概念 | 底层表示 |
|---|---|
| 根对象（type=root，持 root DEK + repoKeyIdSeed） | SECRET 对象；key = manifest 记录的 `rootObjectUuid`（O(1) 定位，见 04） |
| 组记录（type/name/parent/dek） | SECRET 对象；key = `<组UUID>` |
| 条目记录（type/name/parent/icon） | SECRET 对象；key = `<条目UUID>` |
| 预设字段（type=field，name 固定预设名） | SECRET 对象；key = `确定性uuid(nameUUIDFromBytes(entryUuid+"/"+name))` |
| 自定义字段（type=customField；自述 parent + name + kind） | SECRET 对象；key = `<随机UUID>` |
| SSH 私钥（type=sshKey） | SECRET 对象；key = `<随机UUID>` |
| 远端配置（type=remote，独立类型） | SECRET 对象；key = `<随机UUID>` |
| 自定义图标（type=icon，自述 parent） | SECRET 对象；key = `<随机UUID>` |

- **统一按 uuid 分片到两层目录**：对象文件 = `{uuid前2字符}/{剩余字符}.md`（见 04），**无目录嵌套、无保留名、无明文/密文前缀**；文件外观完全一致，外部无法区分明文与密文。
- **内容自描述**：解密负载带 `type` 字段（root/group/entry/field/customField/sshKey/icon/remote，均为 SECRET 对象；manifest 为明文引导块，见 04），解锁扫描按 type 分类定位。**加密归属统一走 data 根 DEK**——图标、SSH 密钥、远端配置不区分 DEK，仅按节点类型分树；文件夹 DEK 在 group 的 `dek` 字段；外部密钥是 customField 的 `kind="externalKey"`（远端配置已独立为 type=remote，见下）。
- 全部走 `put(uuid, data, codec, timestamp)`（当前适配器全密文）。
- 条目/组 id 在创建时用混合熵源（见 02"熵混合"）生成 UUID v4，**终身不变、与内容无关**；预设字段 id 为确定性 uuid（由条目 id 派生），其余对象为随机 uuid。
- **仓库无用户内容明文对象**：当前适配器除 manifest 明文引导块（见 04）外全密文。

## 条目记录内容（加密 JSON）

```json
{
  "version": 1,
  "type": "entry",
  "name": "微博",
  "parent": "<组UUID>",
  "icon": null
}
```

- `parent` = data 根对象 uuid（顶层，无文件夹）；`icon` 为自定义图标（引用 icon 对象 UUID，非归属，优先于内置 `iconId`）。
- **字段值不存于条目记录**：预设字段与自定义字段各自是独立块，自述归属（`parent`），目录扫描时按 `parent` 聚合出条目内容。
- **引用 vs 归属（彻底分离）**：`parent` 是层级归属（决定挂在树的哪、用哪个 DEK 加密）；**引用是另一回事，不算 parent**——group/entry 用 `icon` 字段引用 icon 对象、remote 用 `keyRef` 引用 sshKey。

预设字段块（加密 JSON，确定性 uuid，GUI 固定显示不可删除）：

```json
{ "version": 1, "type": "field", "parent": "<条目UUID>", "name": "password", "value": "..." }
```

- 预设字段名集合（`EntryFields.PRESET_NAMES`）：`password` / `url` / `username` / `labels` / `createTime` / `updateTime`。
- 块 uuid = `nameUUIDFromBytes(entryUuid + "/" + name)`，稳定定位；value 为空则块不落盘（读取时显示空，缺失时回退读 entry 旧字段以兼容迁移）。
- `createTime`/`updateTime` 只读（创建/更新时写入毫秒）。

自定义字段块（加密 JSON，type=customField）：

```json
{ "version": 1, "type": "customField", "parent": "<条目UUID>", "name": "note", "value": "...", "kind": "text" }
```

**自定义字段统一格式**：`{ version, type:"customField", parent, name, value, kind? }`。
- `parent`：所属条目 UUID（自下往上，字段自述归属）。
- `name`：字段名（自述，替代 entry 的 fields 字典键）；**预设字段名不可用于自定义字段**（创建时拒绝）。
- `value`：字段值（统一字符串）。
- `kind`（可选，**存在字段块内**，自描述呈现提示）：`text`（默认）/ `password` / `totp` / `url` / `externalKey` 等，仅作呈现/语义提示，非强类型。TOTP = `kind:"totp"`（种子在 value，用 JDK HmacSHA1 生成验证码，见 02）；外部密钥 = `kind:"externalKey"`（value 即密钥材料，供外部加解密服务，见 02）。
- **兼容读取**：旧数据 `type:"field"` 且 `name` 非预设名 → 视为自定义字段（向后兼容）。
- **不新增字段对象类型**：TOTP、外部密钥都仍是 customField 对象，只是 `kind` 不同；kind 随对象存储。

图标对象（`type:"icon"`）**层级归属**：`parent` 指向 data 根对象（用 data 根 DEK 加密）；同时可被 group/entry 的 `icon` 字段**引用**（引用 ≠ 层级）。

## 文件夹 DEK（密钥树）

**单一 data 根对象**（`type=root`，uuid 由 manifest 记录）持 **用 KEK 包裹的 root DEK** 与 **repoKeyIdSeed**，是"对象用所属 DEK 加密"的基础（见 02"根对象 DEK 与 manifest 内容"）：

- 普通对象树子文件夹 DEK 用**父 DEK**包裹（链式，普通对象树内）。
- group 负载的 `dek` 字段 = 被父 DEK 包裹的本文件夹 DEK。
- **加密归属**：普通对象树内条目/字段用所属文件夹的 DEK（经 HKDF 派生 encKey）加密；顶层条目/字段、图标、SSH 密钥、远端配置均用 **data 根 DEK**。块的 keyId 指向所属 DEK。
- **一对多 / 一对一**：同一文件夹内条目共享其 DEK（一对多）；不同文件夹各自独立（反聚类到文件夹粒度）。
- 普通块**不新增 keyRef 字段**——与哪个 DEK 配对完全由头部 `keyId` 决定。
- 解锁流程（惰性增量）：找 manifest（明文块，type=manifest）→ 派生 KEK → 按 `rootObjectUuid` O(1) 定位根对象、KEK 试解出 root DEK 与 repoKeyIdSeed → 沿普通对象树递归解出各子文件夹 DEK（链式，可任意深度）→ 每得 DEK 即时建 keyId 索引条目 → 普通块按 (nonce, keyId) 找 DEK 试解（见 02）。
- **新对象归属根**：普通节点顶层 `parent` 为 **data 根对象 uuid**（`ObjectTree.createGroup` 顶层传 rootUuid），而非概念 tag；图标/SSH 密钥/远端配置顶层 `parent` 同样为 data 根对象 uuid（见 04）。

- 字段名、字段数量、归属关系全部在加密的字段块/条目记录内：外部不可见。
- 字段对象大小可见，但因按 uuid 分片、无法与条目关联；明文/密文亦不可区分（见"映射"）。
- 组记录：`type`、`version`、`name`、`parent`、`dek`。
- **写入时间戳不存于负载**：每块写入时间戳（毫秒，见 02"仓库时间戳"）存于**落盘前缀**（`timestamp:base58`），用于同步冲突仲裁（大者 wins）；负载 JSON 除 manifest 的 `updateTimestamp` 外不再携带时间戳字段。

## 局部性

- 改任一字段值 → 只重写该字段块（一个文件）；条目记录与其他对象不动，git 只见一个文件变化。
- 改名 / 移动条目（改 parent）→ 只重写条目记录。
- 改字段 kind（`updateKind`）→ 只重写该 customField 块。
- 改名文件夹（`rename`）→ 只重写该 group 记录（加密归属沿用创建时的 DEK 路由）。
- 增删自定义字段 → 新建/删除 customField 块（改字段自身，不动条目）。
- 换图标 → 新建/删除 icon 对象，更新引用方的 `icon` 字段（引用，非归属）。
- 换主密码 → 只重写根对象（type=root，root DEK 用新 KEK 重新包裹）+ 更新 manifest 的 MAC（KEK 派生验证密钥随主密码变化）；普通对象树子文件夹 DEK 链不动，普通对象不动（见 02）。

## 合并行为

- **字段值冲突 = 文件级**：两端改不同字段 → 不同字段块 → git 自动合并；两端改同一字段块 → 文件级冲突，按块前缀时间戳大者 wins（见 06 自动冲突策略），无需应用层三方合并。
- **条目记录冲突（低频）**：仅当两端同时改元数据或归属（如改名/改 parent）时发生 → 按时间戳大者 wins（见 06）。字段增删不冲突（各字段独立块，自述归属）。

## 一致性规则

- **无权威锚点**：事实来源 = 全部对象自身；解锁扫描 + 内容自描述构建内存目录，任何对象损坏/缺失只影响自身，目录可随时重建。
- 锁定期无目录（UI 显示锁定态）；解锁后目录构建于内存，锁定即丢弃。
- 条目归属：条目记录内 `parent` 为准；删组后其成员条目在扫描重建时发现组不存在，惰性归入普通对象树顶层（parent 为 data 根对象 uuid，无需立即改写文件）。
- 孤儿对象（条目删除后遗留的字段块等）无害（git 历史兜底），可提供显式 GC 命令。

## 负载类型字段定义

**根概念 RootTag（enum）**：仅 `DATA("data")`。仓库只有一个根对象（`type=root`），uuid 由 manifest 的 `rootObjectUuid` 记录；所有顶层对象的 `parent` 字段即该**根对象 uuid**（普通节点 `parent` 为父对象 uuid）。图标、SSH 密钥、远端配置按节点类型分树（`IconTree`/`SshKeyTree`/`RemoteTree`），但顶层 parent 同为 data 根对象 uuid、加密统一走 data 根 DEK。

所有负载统一 JSON，首字段固定为 `version`（JSON 结构版本）与 `type`（类型标识）。密文块解密后按 `type` 分类；manifest 为明文引导块（见 02/04）。**写入时间戳存于落盘前缀**（`timestamp:base58`，见 02"仓库时间戳"），不占负载字段（manifest 除外）。

### manifest（明文块）

| 字段 | 类型 | 说明 |
|---|---|---|
| version | int | JSON 结构版本 |
| type | string | 固定 `manifest` |
| cryptoVersion | string | 算法套件版本（见 02） |
| kdf | string | 固定 `argon2id` |
| salt | string(base64) | Argon2id 盐，创建时生成、终身不变 |
| params | object | `{m, i, p}`：memory / iterations / parallelism |
| rootObjectUuid | string(uuid) | 仓库唯一根对象（type=root）的 uuid，解锁 O(1) 定位（见 04） |
| updateTimestamp | long | 本块写入时间戳（毫秒，见 02"仓库时间戳"） |

> MAC **不在 JSON 内**，尾附于块末（`HMAC-SHA256(macKey, 时间戳‖信封头‖负载)`，见 02）。无 `warehouseTime` 字段：仓库时间锚点由 `WarehouseClock` 在解锁时扫描计算（会话基座），不持久化（见 02"仓库时间戳"）。

### root（根对象）

仓库唯一根对象（`type=root`），uuid 由 manifest 的 `rootObjectUuid` 记录，负载持**用 KEK 包裹的 root DEK** 与 **repoKeyIdSeed**（见 02"根对象 DEK 与 manifest 内容"）。不暴露为普通树节点（`ObjectTree.find` 对 type=root 返回 null）。

| 字段 | 类型 | 说明 |
|---|---|---|
| version | int | JSON 结构版本 |
| type | string | 固定 `root` |
| dek | string(base64) | 用 KEK 包裹的 root DEK |
| repoKeyIdSeed | string(base64) | 仓库级 keyId 派生种子（32B，见 02"keyId"） |

### group（组/文件夹，含文件夹 DEK）

每个文件夹绑定一个 DEK（见 02"根对象 DEK 与 manifest 内容"）。子文件夹 DEK 用父 DEK 包裹，存于各 group 的 `dek` 字段；顶层 group 用 data 根 DEK 包裹其 DEK。

| 字段 | 类型 | 说明 |
|---|---|---|
| version | int | JSON 结构版本 |
| type | string | 固定 `group` |
| name | string | 组名 |
| parent | string | 父对象 UUID；顶层为 data 根对象 uuid |
| dek | string(base64) | 本文件夹 DEK，被父 DEK（顶层则被 data 根 DEK）包裹 |
| icon | string(uuid) \| null | 自定义图标（引用 icon 对象 UUID，非归属） |

### entry（口令条目记录）

| 字段 | 类型 | 说明 |
|---|---|---|
| version | int | JSON 结构版本 |
| type | string | 固定 `entry` |
| name | string | 条目名 |
| parent | string | 所属组 UUID；顶层条目为 data 根对象 uuid |
| icon | string(uuid) \| null | 自定义图标（引用 icon 对象 UUID，非归属） |

> 条目**不记录字段值**：预设字段与自定义字段各自为独立块，自述 `parent`；自定义图标由 `icon` 字段**引用**（非归属）。

### field（预设字段块）

| 字段 | 类型 | 说明 |
|---|---|---|
| version | int | JSON 结构版本 |
| type | string | 固定 `field` |
| parent | string(uuid) | 所属条目 UUID（自下往上，自述归属） |
| name | string | 预设字段名：`password`/`url`/`username`/`labels`/`createTime`/`updateTime` |
| value | string | 字段值（字符串形式；labels 为逗号分隔，createTime/updateTime 为毫秒字符串） |

- 块 uuid = `nameUUIDFromBytes(entryUuid + "/" + name)`（确定性，稳定定位/更新）；value 为空则块不落盘（读取缺失时回退读 entry 旧字段以兼容迁移）。
- GUI 固定显示全部预设字段行（无数据也显示空），**不可删除**。

### customField（自定义字段块）

| 字段 | 类型 | 说明 |
|---|---|---|
| version | int | JSON 结构版本 |
| type | string | 固定 `customField`（兼容读取旧 `field` 且 name 非预设名） |
| parent | string(uuid) | 所属条目 UUID（自下往上，自述归属） |
| name | string | 字段名（**不可用预设字段名**，创建时拒绝） |
| value | string | 字段值（字符串形式） |
| kind | string \| null | 呈现提示（存于块内，见上）。**已知集合 = `FieldKind` enum**（`text`/`password`/`totp`/`url`/`externalKey`）；**未知 kind 原样保留**（向后兼容：GUI 下拉会把库内未知 kind 追加进选项）。`null` 视为 `text`。kind 可修改（`updateKind`） |

### sshKey（SSH 私钥）

| 字段 | 类型 | 说明 |
|---|---|---|
| version | int | JSON 结构版本 |
| type | string | 固定 `sshKey` |
| parent | string(uuid) | data 根对象 uuid（层级归属，用 data 根 DEK） |
| name | string | 密钥名（可选） |
| privateKey | string | PEM 私钥内容（加密存储，用 data 根 DEK） |

### remote（远端配置，独立类型）

远端配置是**独立类型** `type=remote`（`NodeType.REMOTE`，`RemoteTree` 承载），扁平存 `name`/`url`/`keyRef`，顶层 parent 为 data 根对象 uuid、用 data 根 DEK 加密：

| 字段 | 类型 | 说明 |
|---|---|---|
| version | int | JSON 结构版本 |
| type | string | 固定 `remote` |
| parent | string(uuid) | data 根对象 uuid（层级归属） |
| name | string | 远端名（如 `github`） |
| url | string | 远端 URL（暴露托管商，故加密存储） |
| keyRef | string \| null | 使用的密钥——vault 内 SSH 密钥对象 UUID（type=sshKey）或系统 key 名（**引用，非归属**，见 sshKey） |

示例：`{ "type":"remote", "parent":"<根对象uuid>", "name":"github", "url":"...", "keyRef":"<sshKeyUUID 或系统key名>" }`

### icon（自定义图标）

**层级归属**：icon 的 `parent` 指向 **data 根对象**（层级归属，用 data 根 DEK 加密）——**与"被谁引用"完全分离**（层级 vs 引用彻底分离，见 02）。

| 字段 | 类型 | 说明 |
|---|---|---|
| version | int | JSON 结构版本 |
| type | string | 固定 `icon` |
| parent | string(uuid) | data 根对象 uuid（层级归属） |
| data | string(base64) | 图标二进制数据（用 data 根 DEK 加密） |
| format | string | 图标格式（如 `png`） |
