# 05 密码库适配器

密码管理 schema 是插在通用对象存储（04）之上的适配器，全部约定建立于 key + 对象。换成其他数据结构时只换适配器，底层不动。

## 隐私目标

外部（无主密码）拿到仓库，最多只能看到一堆随机命名的密文文件；**看不到**组名、条目名、字段名、字段数量、字段值，连组的数量与嵌套形状也不可见，字段对象的大小也无法关联到具体条目。

## 逻辑模型

- 文件夹（组）：树形，节点 = 组记录（SECRET 对象，含父组引用）。
- 条目 = **条目记录 + 每字段一个独立对象**：
  - 条目记录（SECRET 对象）：元数据（name/parent/createSystemTime/icon…），**不含字段映射**；
  - 每个字段值（内置与自定义同构）各自是一个 SECRET 对象，**自述 `parent`（所属条目）+ `fieldName`**，平铺随机 UUID，与组记录/条目/密钥**完全不可区分**。
- 目录：**非持久对象**——解锁时扫描库根全部对象、解密并按内容类型分类，在内存中构建（组树、条目、字段、密钥、远端配置）；锁定即丢弃。
- **无锚点、无保留名**：所有对象都是随机 UUID 文件，靠内容自描述定位。

## 映射：逻辑概念 → key 与对象

| 逻辑概念 | 底层表示 |
|---|---|
| 组记录（type/name/parent/dek/createSystemTime） | SECRET 对象；key = `<组UUID>`（三个顶层组随机 uuid，KEK 试解识别为 root DEK） |
| 条目记录（type/元数据/字段名→引用映射） | SECRET 对象；key = `<条目UUID>` |
| 字段值（内置与自定义各一个对象；自述 parent + fieldName + kind） | SECRET 对象；key = `<随机UUID>` |
| SSH 私钥（type） | SECRET 对象；key = `<随机UUID>` |
| 远端配置（type/名称/URL/key 引用） | SECRET 对象；key = `<随机UUID>` |
| 自定义图标（自述 parent） | SECRET 对象；key = `<随机UUID>` |

- **统一平铺在库根**：所有对象同一命名空间，key 即文件名（随机 UUID），**无 `data/` 层、无目录嵌套、无保留名、无明文/密文前缀**；文件外观完全一致，外部无法区分明文与密文。
- **引用处声明读取模式**：引用某个对象时，在引用方内容中写明 `{ object: <UUID>, mode: "raw" | "cipher" }`——`raw` 直接读原样字节，`cipher` 解密（GCM-SIV）。mode 即解码器选择器，将来可扩展更多读取方式（如压缩、分块、版本化等，见 04）。
- **内容自描述**：解密负载带 `type` 字段（group/entry/field/sshKey/icon，均为 SECRET 对象；manifest 为明文引导块，见 04b），解锁扫描按 type 分类定位；无需类型前缀或锚点对象。**密钥/远端无独立类型**：文件夹 DEK 在 group 的 `dek` 字段，外部密钥与远端配置是 field 的 `kind`（`externalKey`/`remote`，见 02/05）。
- 全部走 `put(key, data, cipherCodec)`（当前适配器全密文）。存储引擎本身不感知加密，见 04。
- 条目/组 id 在创建时用混合熵源（见 02"熵混合"）生成 UUID v4（RFC 4122：`xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx`，y ∈ 8/9/a/b），**终身不变、与内容无关**（不哈希名字）：改名只改对象内容，id 保持稳定。
- **仓库无用户内容明文对象**：当前适配器除 manifest 明文引导块（见 04b）外全密文（引用 mode 均为 cipher）；`raw` 为引擎能力与未来适配器预留，不产生死机制。

## 条目记录内容（加密 JSON）

```json
{
  "version": 1,
  "type": "entry",
  "name": "微博",
  "parent": "<组UUID>",
  "createSystemTime": 1723449600000,
  "updateTimestamp": 1723449600000,
  "iconId": 1,
  "icon": null
}
```

- `parent` null = 根组（无文件夹）；`iconId` 为内置图标集索引；`icon` 为自定义图标（引用 icon 对象 UUID，非归属，优先于 iconId）。
- **严格自下往上**：entry **不记录字段映射**（无 `fields` 字典）——字段各自**自述归属**（`parent`，见下），目录扫描时按 `parent` 聚合出条目内容。
- **引用 vs 归属（彻底分离）**：`parent` 是层级归属（决定挂在树的哪、用哪个 DEK 加密）；**引用是另一回事，不算 parent**——group/entry 用 `icon` 字段引用 icon 对象、remote 用 `keyRef` 引用 sshKey。被引用的 icon/sshKey 各有自己的 `parent`（icon root / sshKey root group），与"被谁引用"无关。
- `updateTimestamp`（毫秒）：本对象写入时间戳，按全局规则计算（见 02"仓库时间戳"），用于同步冲突仲裁。

字段值对象内容（加密 JSON，与其余对象同构）：

```json
{ "version": 1, "type": "field", "parent": "<条目UUID>", "fieldName": "password", "value": "...", "kind": "text" }
```

**自定义字段统一格式**：`{ version, type:"field", parent, fieldName, value, kind? }`。
- `parent`：所属对象 UUID（自下往上，字段自述归属）——通常指向条目，`kind:"remote"` 时指向所属 group。
- `fieldName`：字段名（自述，替代 entry 的 fields 字典键）。
- `value`：字段值（统一字符串）。
- `kind`（可选，**存在字段块内**，自描述呈现提示）：`text`（默认）/ `password` / `totp` / `url` / `externalKey` / `remote` 等，仅作呈现/语义提示，非强类型。TOTP = `kind:"totp"`（种子在 value，用 HmacOTP 生成验证码，见 02）；外部密钥 = `kind:"externalKey"`（value 即密钥材料，供外部加解密服务，见 02）；远端配置 = `kind:"remote"`（value 含 url/keyRef，见 remote）。
- **不新增字段对象类型**：TOTP、外部密钥都仍是 `field` 对象，只是 `kind` 不同；kind 随对象存储。

图标对象（`type:"icon"`）**层级归属**：`parent` 指向 icon root group（用 icon root DEK 加密）；同时可被 group/entry 的 `icon` 字段**引用**（引用 ≠ 层级，见 icon 表）。

## 文件夹 DEK（密钥树）

**三个顶层 group**（普通对象 / icon / sshKey 各一，都 `parent==null`、随机 uuid、各持一个独立随机且用 KEK 包裹的 DEK），是"对象用所属 root 的 DEK 加密"的基础（见 02"文件夹 DEK"）：

- 普通对象 root group 持普通对象 root DEK；子文件夹 DEK 用**父 DEK**包裹（链式，普通对象树内）。
- icon root group 持 icon root DEK；sshKey root group 持 sshKey root DEK。
- group 负载的 `dek` 字段 = 被父 DEK（三个顶层 root 则被 KEK）包裹的本文件夹 DEK。
- **加密归属**：普通对象树内条目/字段用所属文件夹的 DEK（经 HKDF 派生 encKey）加密；icon 用 icon root DEK；sshKey 用 sshKey root DEK。块的 keyId 指向所属 DEK。
- **一对多 / 一对一**：同一文件夹内条目共享其 DEK（一对多）；不同文件夹各自独立（反聚类到文件夹粒度）。
- 普通块**不新增 keyRef 字段**——与哪个 DEK 配对完全由头部 `keyId` 决定。
- 解锁流程（惰性增量）：找 manifest（明文块，type=manifest）→ 派生 KEK → 解出三个顶层 root 的 DEK → 沿普通对象树递归解出各子文件夹 DEK（链式，可任意深度）→ 每得 DEK 即时建 keyId 索引条目 → 普通块按 keyId 找 DEK 试解（见 02）。
- **新对象归属 root（按 `role`）**：三个顶层 group 用加密的 `role` 字段区分用途（`objects`/`icon`/`sshKey`，见 group）。添加新 icon → parent 指向 `role=="icon"` 的顶层 group；添加 sshKey → `role=="sshKey"`；添加普通条目/子文件夹 → 普通对象树（`role=="objects"` 或已有父 group）。`role` 在加密负载内，外部不可见，不破坏外观统一。

- 字段名、字段数量、归属关系全部在加密的条目记录内：外部不可见。
- 字段对象大小可见，但因平铺随机 UUID、无法与条目关联；明文/密文亦不可区分（见"映射"）。
- 组记录：`type`、`version`、`name`、`parent`、`dek`、`createSystemTime`、`updateTimestamp`；**所有类型负载均带 `updateTimestamp`**（写入时间戳，见 02"仓库时间戳"）。
- `updateTimestamp`：每块写入时按全局时间戳规则计算（毫秒，见 02"仓库时间戳"），用于同步冲突仲裁（大者 wins）。

## 局部性

- 改任一字段值 → 只重写该字段对象（一个文件）；条目记录与其他对象不动，git 只见一个文件变化。
- 改名 / 移动条目（改 parent）→ 只重写条目记录。
- 增删字段 → 新建/软删除 field 对象（改 field 自身，不动条目）。
- 换图标 → 新建/软删除 icon 对象，更新引用方的 `icon` 字段（引用，非归属）。
- 换主密码 → 只重写三个顶层 group（普通对象/icon/sshKey root，各 root DEK 用新 KEK 重新包裹）+ 更新 manifest 的 MAC（KEK 派生验证密钥随主密码变化）；普通对象树子文件夹 DEK 链不动，普通对象不动（见 02）。

## 合并行为

- **字段值冲突 = 文件级**：两端改不同字段 → 不同字段对象 → git 自动合并；两端改同一字段对象 → 文件级冲突，按 `updateTimestamp` 大者 wins（见 06 自动冲突策略），无需应用层三方合并。
- **条目记录冲突（低频）**：仅当两端同时改元数据或归属（如改名/改 parent）时发生 → 按 `updateTimestamp` 大者 wins（见 06）。字段增删不冲突（各字段独立对象，自述归属）。

## 一致性规则

- **无权威锚点**：事实来源 = 全部对象自身；解锁扫描 + 内容自描述构建内存目录，任何对象损坏/缺失只影响自身，目录可随时重建。
- 锁定期无目录（UI 显示锁定态）；解锁后目录构建于内存，锁定即丢弃。
- 条目归属：条目记录内 `parent` 为准；删组后其成员条目在扫描重建时发现组不存在，惰性归入根组（无需立即改写文件）。
- 孤儿对象（条目删除后遗留的字段对象等）无害（git 历史兜底），可提供显式 GC 命令。

## 负载类型字段定义

所有负载统一 JSON，首字段固定为 `version`（JSON 结构版本）与 `type`（类型标识），且**所有类型均带 `updateTimestamp`**（写入时间戳，见 02"仓库时间戳"）。密文块解密后按 `type` 分类；manifest 为明文引导块（见 02/04b）。

- **时间戳区分**：`createSystemTime`（group/entry 等）用**创建时的系统墙钟时间**（`System.currentTimeMillis()`），仅信息性，**不参与冲突仲裁**；`updateTimestamp` 用**仓库时间戳**（单调时钟 + 相对锚点，见 02），用于冲突仲裁。二者来源不同、用途不同。

### manifest（明文块）

| 字段 | 类型 | 说明 |
|---|---|---|
| version | int | JSON 结构版本 |
| type | string | 固定 `manifest` |
| cryptoVersion | string | 算法套件版本（见 02） |
| kdf | string | 固定 `argon2id` |
| salt | string(base64) | Argon2id 盐，创建时生成、终身不变 |
| params | object | `{m, i, p}`：memory / iterations / parallelism |
| warehouseTime | long | 仓库全局时间戳（毫秒），初值 1，仅关闭库时更新（见 02"仓库时间戳"） |
| updateTimestamp | long | 本块写入时间戳（毫秒，见 02"仓库时间戳"），冲突仲裁 |
| mac | string(base64) | KEK 派生验证密钥算的 MAC，防篡改/降级 |

### group（组/文件夹，含文件夹 DEK）

每个文件夹绑定一个 DEK（见 02"文件夹 DEK"）。三个顶层 group（普通对象/icon/sshKey root）用**随机 uuid**（不特殊命名）、`parent==null`、KEK 试解识别为根，各持**root DEK**（用 KEK 包裹）；普通对象树子文件夹 DEK 用父 DEK 包裹。

| 字段 | 类型 | 说明 |
|---|---|---|
| version | int | JSON 结构版本 |
| type | string | 固定 `group` |
| name | string | 组名 |
| role | string \| null | **仅顶层 group 有**（加密存储，外部不可见）：`objects`/`icon`/`sshKey`，标识该 root 用途；子 group 为 null |
| parent | string(uuid) \| null | 父组 UUID；null=顶层（普通对象/icon/sshKey root，KEK 试解识别，各持独立 KEK 包裹的 DEK） |
| dek | string(base64) | 本文件夹 DEK，被父 DEK（顶层则被 KEK）包裹 |
| icon | string(uuid) \| null | 自定义图标（引用 icon 对象 UUID，非归属） |
| createSystemTime | long | 创建时系统时间（墙钟毫秒，非仓库时间戳，仅信息性） |
| updateTimestamp | long | 写入时间戳（毫秒，见 02"仓库时间戳"），冲突仲裁 |

### entry（口令条目记录）

| 字段 | 类型 | 说明 |
|---|---|---|
| version | int | JSON 结构版本 |
| type | string | 固定 `entry` |
| name | string | 条目名 |
| parent | string(uuid) \| null | 所属组 UUID，null=根组 |
| iconId | int \| null | 内置图标集索引 |
| icon | string(uuid) \| null | 自定义图标（引用 icon 对象 UUID，非归属；优先于 iconId） |
| createSystemTime | long | 创建时系统时间（墙钟毫秒，非仓库时间戳，仅信息性） |
| updateTimestamp | long | 写入时间戳（毫秒，见 02"仓库时间戳"），冲突仲裁 |

> 条目**不记录字段映射**（严格自下往上，见上文）：字段自述 `parent`；自定义图标由 `icon` 字段**引用**（非归属）。

### field（字段值对象）

| 字段 | 类型 | 说明 |
|---|---|---|
| version | int | JSON 结构版本 |
| type | string | 固定 `field` |
| parent | string(uuid) | 所属条目 UUID（自下往上，自述归属） |
| fieldName | string | 字段名（自述，替代 entry 的 fields 字典键） |
| value | string | 字段值（字符串形式） |
| kind | string \| null | 呈现提示（存于块内，见上）：`text`/`password`/`totp`/`url`/`externalKey`/`remote`，TOTP 用 `totp` |
| updateTimestamp | long | 写入时间戳（毫秒，见 02"仓库时间戳"），冲突仲裁 |

### sshKey（SSH 私钥）

| 字段 | 类型 | 说明 |
|---|---|---|
| version | int | JSON 结构版本 |
| type | string | 固定 `sshKey` |
| parent | string(uuid) | 所属 sshKey root group（层级归属，见 02/文件夹 DEK） |
| name | string | 密钥名（可选） |
| privateKey | string | PEM 私钥内容（加密存储，用 sshKey root DEK） |
| updateTimestamp | long | 写入时间戳（毫秒，见 02"仓库时间戳"），冲突仲裁 |

### remote（远端配置 = field 的 kind，无独立类型）

远端配置不再有独立类型，而是**某 group 的自定义字段**，`kind:"remote"`（见 field）。字段值含：

- `url`：远端 URL（暴露托管商，故加密存储）。
- `keyRef`：使用的密钥——vault 内 SSH 密钥对象 UUID（type=sshKey）或系统 key 名（**引用，非归属**，见 sshKey）。

示例：`{ "type":"field", "parent":"<groupUUID>", "fieldName":"github", "kind":"remote", "value": { "url":"...", "keyRef":"<sshKeyUUID 或系统key名>" } }`

### icon（自定义图标）

**层级归属**：icon 的 `parent` 指向 **icon root group**（层级归属，用 icon root DEK 加密）——**与"被谁引用"完全分离**（层级 vs 引用彻底分离，见 02/文件夹 DEK）。

| 字段 | 类型 | 说明 |
|---|---|---|
| version | int | JSON 结构版本 |
| type | string | 固定 `icon` |
| parent | string(uuid) | 所属 icon root group（层级归属） |
| data | string(base64) | 图标二进制数据（用 icon root DEK 加密） |
| format | string | 图标格式（如 `png`） |
| updateTimestamp | long | 写入时间戳（毫秒，见 02"仓库时间戳"），冲突仲裁 |

> `sshKey`/`icon` 的具体字段为初拟，待逐个讨论确认（见 09 路线）。
