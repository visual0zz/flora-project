# decision: 底层存储布局固化与独立仓库形态（2026-08-20）

> 涉及 flora-sanctum 大规模重构：存储布局、独立仓库、GUI 四页、数据模型预设字段。对应需求 1-6。

## 决策 1：存储固化为一文件一块 + git 风格两层目录

- **格式**：`root/{xx}/{rest}.md`，`xx` = uuid 无连字符 hex 前 2 字符，`rest` = 剩余 30 字符；每文件恰一行 `timestamp:base58`。
- **去除**：一个文件多个块、用户正文与密文交错（旧格式兼容已删除）。
- **uuid**：继续用 `UUID.randomUUID()`（v4，122 位随机）。验证前 2 字符（第 1 字节 8 位）在 256 桶均匀分布（测试 `MarkdownObjectStoreTest.uuidPrefixUniform`），**无需更换生成方式**；文件名去连字符。

**Why**: 两层目录避免单目录文件爆炸；一文件一块简化扫描/定位（O(1) 定位替代全库扫描）；去交错让文件即块、内容纯粹。
**How to apply**: 存储层 `ObjectStore` 接口不变，`MarkdownObjectStore` 内部实现改为路径派生；`Block.line()` 固定为 1。

## 决策 2：独立仓库 = { standalone.json, data/, lib/, 启动脚本 }

- **data/**：两层目录 + uuid.md（普通仓库即此结构）。
- **lib/**：应用全量 jar（构建时从主类 CodeSource 或 CWD/lib 复制）。
- **启动脚本**：双头脚本（bash + cmd），`JAVA_HOME` 优先、PATH fallback；module-path 启动；git 可选（运行时探测）。

**Why**: 独立仓库自包含可分发；jar 定位按 module-path / classpath / 分发目录三种方式兜底。
**How to apply**: `RepoCreator.createStandalone` 自动定位 jar 复制，无需外部传 lib 源。

## 决策 3：形态判定落 jar 内，基于 standalone.json

- jar 启动时检测**当前工作目录**与 **jar 所在目录**的 `standalone.json`，存在即孤立形态。
- standalone.json 存储仓库级配置（使用习惯，非机密），与应用级配置（`~/.flora-sanctum/config.json`）同结构，`UserConfig` 统一承载。

**Why**: 判定不依赖脚本传参（用户明确要求落 jar 内）；配置随仓库走，便于独立分发。
**How to apply**: `VaultForm.detectStandaloneRoot()` / `VaultForm.detect(dir)` / `UserConfig(Path)` 已实现。

## 决策 4：GUI 四页 + 解锁流程

- 页面：**编辑页 / 历史仓库列表页 / 仓库设置页 / 解锁页**。
- 独立形态：解锁 → 编辑 → 设置（无历史列表，工具栏隐藏"切换库"）。
- 应用形态：历史列表 → 解锁 → 编辑；锁定/超时**直接回到该仓库解锁页**（不退回历史），解锁页带"回到历史列表"按钮。
- "新建 / 导入 / 打开"从独立选择页合并进历史列表页（删除 `SelectScreen`）。

**Why**: 锁定后立即重新输入密码（同一仓库）比退回列表更快更自然；独立形态不暴露多仓库概念。
**How to apply**: `SanctumGui` 状态机：`pendingRoot` 记录当前仓库，`showHistoryPage/showUnlockPage/showEditPage/showSettingsPage` 切换。

## 决策 5：预设字段独立块 + field→customField

- entry 预设字段（password/url/username/labels/createTime/updateTime）改为独立块存储：
  - 块 type=field，fieldName 固定为预设名，**确定性 uuid** `nameUUIDFromBytes(entryUuid + "/" + fieldName)`。
  - entry 块只保留 name/parent/icon 等结构信息；旧 entry JSON 预设字段读取时回退兼容。
- 自定义字段块 type 改为 **customField**（读时兼容旧 type=field 且非预设名）。
- GUI 预设字段行固定显示（无数据也显示）、不可删除；自定义字段区可增删。

**Why**: 预设字段与自定义字段统一为块（对象局部性/加密粒度一致）；确定性 uuid 使预设字段定位 O(1)；"显示不变"降低 GUI 改动。
**How to apply**: `EntryNode` 读写预设块；`ObjectTree.belongsTo` 纳入 customField；`EntryNode.createField` 拒绝预设名。

## 验证

- core 53 + app 10 用例全绿（含新 `MarkdownObjectStoreTest` 布局/uuid 均匀性、`VaultFormTest` standalone.json）。
- 性能：创建 40 entry ≈ 2.5s，无存储回归；SanctumTest 慢源于 Argon2 固有开销。
