# 05 密码库适配器

密码管理 schema 是插在通用对象存储（04）之上的适配器，全部约定建立于 key + 对象。换成其他数据结构时只换适配器，底层不动。

## 隐私目标

外部（无主密码）拿到仓库，最多只能看到一堆随机命名的密文文件；**看不到**组名、条目名、字段名、字段数量、字段值，连组的数量与嵌套形状也不可见，字段对象的大小也无法关联到具体条目。

## 逻辑模型

- 文件夹（组）：树形，节点 = 组记录（SECRET 对象，含父组引用）。
- 条目 = **条目记录 + 每字段一个独立对象**：
  - 条目记录（SECRET 对象）：元数据（name/groupId/createdAt/icon…）+ 字段名 → 字段对象 UUID 的映射；
  - 每个字段值（内置与自定义同构）各自是一个 SECRET 对象，平铺随机 UUID，与组记录/条目/密钥**完全不可区分**。
- 目录：**非持久对象**——解锁时扫描库根全部对象、解密并按内容类型分类，在内存中构建（组树、条目、字段、密钥、远端配置）；锁定即丢弃。
- **无锚点、无保留名**：所有对象都是随机 UUID 文件，靠内容自描述定位。

## 映射：逻辑概念 → key 与对象

| 逻辑概念 | 底层表示 |
|---|---|
| 组记录（type/name/parentGroupId/createdAt） | SECRET 对象；key = `<组UUID>` |
| 条目记录（type/元数据/字段名→引用映射） | SECRET 对象；key = `<条目UUID>` |
| 字段值（内置与自定义各一个对象） | SECRET 对象；key = `<随机UUID>`（条目记录引用） |
| SSH 私钥（type） | SECRET 对象；key = `<随机UUID>` |
| 远端配置（type/名称/URL/key 引用） | SECRET 对象；key = `<随机UUID>` |
| 自定义图标 | SECRET 对象；key = `<随机UUID>`（条目记录以 iconObjectId 引用，可选） |
| 库密钥（vaultKey/type/DEK，见"库密钥块"） | SECRET 对象；key = `<随机UUID>`（普通块以头部 keyId 指向） |
| 外部密钥（extKey/type/secret，见 02） | SECRET 对象；key = `<随机UUID>`（外部以对象 UUID 引用，服务外部数据加解密） |

- **统一平铺在库根**：所有对象同一命名空间，key 即文件名（随机 UUID），**无 `data/` 层、无目录嵌套、无保留名、无明文/密文前缀**；文件外观完全一致，外部无法区分明文与密文。
- **引用处声明读取模式**：引用某个对象时，在引用方内容中写明 `{ object: <UUID>, mode: "raw" | "cipher" }`——`raw` 直接读原样字节，`cipher` 解密（GCM-SIV）。mode 即解码器选择器，将来可扩展更多读取方式（如压缩、分块、版本化等，见 04）。
- **内容自描述**：解密负载带 `type` 字段（vaultKey/extKey/group/entry/field/sshKey/remote/icon，均为 SECRET 对象；manifest 为明文引导块，见 04b），解锁扫描按 type 分类定位；无需类型前缀或锚点对象。
- 全部走 `put(key, data, cipherCodec)`（当前适配器全密文）。存储引擎本身不感知加密，见 04。
- 条目/组 id 在创建时用混合熵源（见 02"熵混合"）生成 UUID v4（RFC 4122：`xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx`，y ∈ 8/9/a/b），**终身不变、与内容无关**（不哈希名字）：改名只改对象内容，id 保持稳定。
- **仓库无用户内容明文对象**：当前适配器除 manifest 明文引导块（见 04b）外全密文（引用 mode 均为 cipher）；`raw` 为引擎能力与未来适配器预留，不产生死机制。

## 条目记录内容（加密 JSON）

```json
{
  "version": 1,
  "type": "entry",
  "name": "微博",
  "groupId": "<组UUID>",
  "createdAt": "2026-08-12T10:00:00Z",
  "modifiedAt": 1723449600000,
  "iconId": 1,
  "iconObjectId": null,
  "fields": {
    "password": { "object": "<字段对象UUID>", "mode": "cipher" },
    "username": { "object": "<字段对象UUID>", "mode": "cipher" },
    "自定义字段": { "object": "<字段对象UUID>", "mode": "cipher" }
  }
}
```

- `groupId` null = 根组（无文件夹）；`iconId` 为内置图标集索引；`iconObjectId` 为自定义图标（SECRET 对象 UUID），存在即优先于 iconId。
- `modifiedAt`（毫秒）：本对象写入时间戳，按全局规则计算（见 02"仓库时间戳"），用于同步冲突仲裁。

字段值对象内容（加密 JSON，与其余对象同构）：

```json
{ "version": 1, "type": "field", "value": "...", "kind": "text" }
```

**自定义字段统一格式**：`{ version, type:"field", value, kind? }`。
- `value`：字段值（统一字符串）。
- `kind`（可选，**存在字段块内**，自描述呈现提示）：`text`（默认）/ `password` / `totp` / `url` 等，仅作 UI 呈现提示，非强类型。TOTP = `kind:"totp"`（种子在 value，用 HmacOTP 生成验证码，见 02）。
- **不新增字段对象类型**：TOTP 仍是 `field` 对象，只是 `kind` 不同；kind 随对象存储，被多处引用时一致。

## 库密钥块（vaultKey）

**vaultKey 类型块存放库 DEK**，是"任意块用任意存储的密钥解密"的基础。所有负载统一 JSON，vaultKey 也如此：

```json
{ "version": 1, "type": "vaultKey", "dek": "<base64>" }
```

- **`dek`**：一个库 DEK（256 位随机），用主密钥派生的 KEK 包裹（加密后 base64）。vaultKey 块**自身信封用 KEK 加密**（头部 keyId 为 KEK 派生变体，见 02），不参与普通块的 DEK-keyId 索引。
- **多个 vaultKey 块可共存**：一个库可有多个独立 DEK，每块普通密文头部的 keyId 决定它用哪个 DEK 解密（见 02 定位机制）。
- **一对一 / 一对多**：
  - 一对多：多个普通块头 keyId 指向同一个 vaultKey 的 DEK → 共享密钥。
  - 一对一：每块引用自己专属的 vaultKey → 独立密钥、最强反聚类。
- 普通块**不新增 keyRef 字段**——它们与哪个密钥配对完全由头部 `keyId` 决定（无需在负载里引用）。
- 解锁流程（惰性增量）：找 manifest（明文块，type=manifest）→ 派生 KEK → 用已知密钥为工作队列试解块，解出 vaultKey 即得新 DEK、入队继续（库密钥可任意链式/嵌套依赖）→ 每得 DEK 即时建 keyId 索引条目 → 普通块按 keyId 找 DEK 试解（见 02）。

- 字段名、字段数量、归属关系全部在加密的条目记录内：外部不可见。
- 字段对象大小可见，但因平铺随机 UUID、无法与条目关联；明文/密文亦不可区分（见"映射"）。
- 组记录：`type`、`version`、`name`、`parentGroupId`、`createdAt`、`modifiedAt`；密钥（vaultKey）/远端配置对象同样带 `type`，普通对象均带 `modifiedAt`（冲突仲裁时间戳，见 06）。
- `modifiedAt`：每块写入时按全局时间戳规则计算（毫秒，见 02"仓库时间戳"），用于同步冲突仲裁（大者 wins）。

## 局部性

- 改任一字段值 → 只重写该字段对象（一个文件）；条目记录与其他对象不动，git 只见一个文件变化。
- 改名 / 增删字段 / 换图标 / 移动条目（改 groupId）→ 只重写条目记录。
- 换主密码 → 重写全部 vaultKey 块（新 KEK 重新包裹，DEK 不变）+ 更新 manifest 的 MAC（KEK 派生验证密钥随主密码变化），普通对象不动（见 02）。

## 合并行为

- **字段值冲突 = 文件级**：两端改不同字段 → 不同字段对象 → git 自动合并；两端改同一字段对象 → 文件级冲突，按 `modifiedAt` 大者 wins（见 06 自动冲突策略），无需应用层三方合并。
- **条目记录冲突（低频）**：仅当两端同时改元数据或字段映射（如都增删/改名）时发生 → 按 `modifiedAt` 大者 wins，或应用层按字段名合并映射（见 06）。

## 一致性规则

- **无权威锚点**：事实来源 = 全部对象自身；解锁扫描 + 内容自描述构建内存目录，任何对象损坏/缺失只影响自身，目录可随时重建。
- 锁定期无目录（UI 显示锁定态）；解锁后目录构建于内存，锁定即丢弃。
- 条目归属：条目记录内 `groupId` 为准；删组后其成员条目在扫描重建时发现组不存在，惰性归入根组（无需立即改写文件）。
- 孤儿对象（条目删除后遗留的字段对象等）无害（git 历史兜底），可提供显式 GC 命令。

## 负载类型字段定义

所有负载统一 JSON，首字段固定为 `version`（JSON 结构版本）与 `type`（类型标识）。密文块解密后按 `type` 分类；manifest 为明文引导块（见 02/04b）。

### manifest（明文块）

| 字段 | 类型 | 说明 |
|---|---|---|
| version | int | JSON 结构版本 |
| type | string | 固定 `manifest` |
| cryptoVersion | string | 算法套件版本（见 02） |
| kdf | string | 固定 `argon2id` |
| salt | string(base64) | Argon2id 盐，创建时生成、终身不变 |
| params | object | `{m, i, p}`：memory / iterations / parallelism |
| warehouseTime | long | 仓库全局时间戳（毫秒），初值 1，仅关闭库时更新（见 02"仓库时间戳"） |
| mac | string(base64) | KEK 派生验证密钥算的 MAC，防篡改/降级 |

### vaultKey（库密钥）

| 字段 | 类型 | 说明 |
|---|---|---|
| version | int | JSON 结构版本 |
| type | string | 固定 `vaultKey` |
| dek | string(base64) | 库 DEK（256 位随机），KEK 包裹（vaultKey 块自身信封用 KEK，见 02） |

### extKey（外部密钥）

格式与 vaultKey **完全同构**（标准块信封 + KEK 包裹的密钥材料），**仅 type 不同**；专用于外部数据加解密，见 02。

| 字段 | 类型 | 说明 |
|---|---|---|
| version | int | JSON 结构版本 |
| type | string | 固定 `extKey` |
| secret | string(base64) | 外部密钥材料（KEK 包裹），供外部数据加解密 |
| name | string | 可选名称 |
| description | string | **用途描述**（必须），`list()` 返回用；说明这把密钥用于什么 |

**激活约束**：extKey **不是根对象**，必须被某个数据条目作为子属性（`fields[]` 或专门引用）指向才**生效**；未被引用的 extKey 不在 GC 可达树内，视为未激活/可清理，`list()` 不列出。外部解密候选域 = 仅激活的 extKey（见 02"防泄漏"）。

### group（组/文件夹）

| 字段 | 类型 | 说明 |
|---|---|---|
| version | int | JSON 结构版本 |
| type | string | 固定 `group` |
| name | string | 组名 |
| parentGroupId | string(uuid) \| null | 父组 UUID，null=根组 |
| createdAt | string(ISO8601) | 创建时间 |
| modifiedAt | long | 写入时间戳（毫秒，见 02"仓库时间戳"），冲突仲裁 |

### entry（口令条目记录）

| 字段 | 类型 | 说明 |
|---|---|---|
| version | int | JSON 结构版本 |
| type | string | 固定 `entry` |
| name | string | 条目名 |
| groupId | string(uuid) \| null | 所属组 UUID，null=根组 |
| createdAt | string(ISO8601) | 创建时间 |
| iconId | int \| null | 内置图标集索引 |
| iconObjectId | string(uuid) \| null | 自定义图标对象 UUID，存在即优先于 iconId |
| fields | object | 字段名 → `{object, mode}` 映射 |
| modifiedAt | long | 写入时间戳（毫秒，见 02"仓库时间戳"），冲突仲裁 |

### field（字段值对象）

| 字段 | 类型 | 说明 |
|---|---|---|
| version | int | JSON 结构版本 |
| type | string | 固定 `field` |
| value | string | 字段值（字符串形式） |
| kind | string \| null | 呈现提示（存于块内，见上）：`text`/`password`/`totp`/`url`，TOTP 用 `totp` |
| modifiedAt | long | 写入时间戳（毫秒，见 02"仓库时间戳"），冲突仲裁 |

### sshKey（SSH 私钥）

| 字段 | 类型 | 说明 |
|---|---|---|
| version | int | JSON 结构版本 |
| type | string | 固定 `sshKey` |
| name | string | 密钥名（可选） |
| privateKey | string | PEM 私钥内容（加密存储） |
| modifiedAt | long | 写入时间戳（毫秒，见 02"仓库时间戳"），冲突仲裁 |

### remote（远端配置）

| 字段 | 类型 | 说明 |
|---|---|---|
| version | int | JSON 结构版本 |
| type | string | 固定 `remote` |
| name | string | 远端名 |
| url | string | 远端 URL（暴露托管商，故加密存储） |
| keyRef | string(uuid) \| null | 使用的密钥：vault 内 SSH 密钥对象 UUID（type=sshKey）或系统 key 名 |
| modifiedAt | long | 写入时间戳（毫秒，见 02"仓库时间戳"），冲突仲裁 |

### icon（自定义图标）

| 字段 | 类型 | 说明 |
|---|---|---|
| version | int | JSON 结构版本 |
| type | string | 固定 `icon` |
| data | string(base64) | 图标二进制数据 |
| format | string | 图标格式（如 `png`） |
| modifiedAt | long | 写入时间戳（毫秒，见 02"仓库时间戳"），冲突仲裁 |

> `sshKey`/`icon` 的具体字段为初拟，待逐个讨论确认（见 09 路线）。
